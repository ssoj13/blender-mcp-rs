**********************
Face Set Gesture Tools
**********************

Face Set gesture tools apply a single new Face Set to all faces within the selection area.

All Face Set gesture tools can be activated in the Toolbar and are comprised of the following:

.. _tool-box-face-set:

Box Face Set
============

Creates a new Face Set </sculpt_paint/sculpting/editing/face_sets>
based on a box gesture <gesture-tool-box>.

.. _tool-lasso-face-set:

Lasso Face Set
==============

Creates a new Face Set </sculpt_paint/sculpting/editing/face_sets>
based on a lasso gesture <gesture-tool-lasso>.

.. _tool-line-face-set:

Line Face Set
=============

Creates a new Face Set </sculpt_paint/sculpting/editing/face_sets>
based on a line gesture <gesture-tool-line>.

.. _tool-polyline-face-set:

Polyline Face Set
=================

Creates a new Face Set </sculpt_paint/sculpting/editing/face_sets>
based on a polyline gesture <gesture-tool-polyline>.

Tool Settings
=============

Front Faces Only
   Only creates a face set on the faces that face towards the view.
