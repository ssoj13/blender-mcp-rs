******************
Mask Gesture Tools
******************

Mask gesture tools apply a constant value to all selected vertices within the selection area.
By default, these tools fully mask each vertex. Holding Ctrl while performing the selection
clears the mask.

All mask gesture tools can be activated in the Toolbar and are comprised of the following:

.. _tool-box-mask:

Box Mask
========

Creates a new Mask </sculpt_paint/sculpting/editing/mask> based on a
box gesture <gesture-tool-box>.

.. _tool-lasso-mask:

Lasso Mask
==========

Creates a new Mask </sculpt_paint/sculpting/editing/mask> based on a
lasso gesture <gesture-tool-lasso>.

.. _tool-line-mask:

Line Mask
=========

Creates a new Mask </sculpt_paint/sculpting/editing/mask> based on a
line gesture <gesture-tool-line>.

.. _tool-polyline-mask:

Polyline Mask
=============

Creates a new Mask </sculpt_paint/sculpting/editing/mask> based on a
polyline gesture <gesture-tool-polyline>.

Tool Settings
=============

Front Faces Only
   Only creates a mask on the faces that face towards the view.
