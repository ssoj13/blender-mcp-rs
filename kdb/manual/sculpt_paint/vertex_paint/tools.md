******************
Vertex Paint Tools
******************

Brush
   Tool to use for any of the vertex paint brushes <brushes>.

Annotate <tool-annotate-freehand>
   Draw free-hand annotation.

   Annotate Line
      Draw straight line annotation.
   Annotate Polygon
      Draw a polygon annotation.
   Annotate Eraser
      Erase previous drawn annotations.
