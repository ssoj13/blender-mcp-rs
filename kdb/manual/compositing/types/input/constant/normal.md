.. _bpy.types.CompositorNodeNormal:

***********
Normal Node
***********

The Normal node generates a normal vector.

Inputs
======

Normal
   Normal vector input.

Properties
==========

Normal Direction
   To manually set a fixed normal direction vector.
   LMB click and drag on the sphere to set the direction of the normal.
   Holding Ctrl while dragging snaps to 45 degree rotation increments.

Outputs
=======

Normal
   Normal vector output.
