.. _bpy.types.TextureNodeChecker:

************
Checker Node
************

The Checker node creates a checkerboard pattern.

Inputs
======

Color 1, Color 2
   The colors of the squares.
Size
   The scale of the checker pattern.

Properties
==========

This node has no properties.

Outputs
=======

Color
   Standard color output.
