Action Panel
============

When the editor is in Action Editor </editors/dope_sheet/modes/action> mode,
or in Dope Sheet mode with a channel selected that belongs to an action,
this panel allows changing some settings of that action.
See Action Properties <actions-properties> for details.

Custom Properties
=================

Create and manage your own properties to store data in the action's data block.
See the Custom Properties <files-data_blocks-custom-properties> page for more information.
