**************
Fluid Modifier
**************

The Fluid modifier is a container for a Fluid Physics </physics/fluid/index> simulation. It can be useful
for example, to simulate on a low-poly mesh then add a /modeling/modifiers/generate/subdivision_surface
after the Fluid modifier to improve the visual quality of the fluid without drastically increasing simulation times.

Options
=======

As the modifier is only a container its actual options can be configured in the *Physics Properties* tab.
See the Fluid Physics Properties </physics/fluid/index> for more information.
