*******
Toolbar
*******

The following tools are available in Edit Mode:

Select </interface/selecting>
   Select control points.
Cursor
   Change the location of the 3D Cursor </editors/3dview/3d_cursor>.
Move
   Translation tool.
Rotate
   Rotation tool.
Scale
   Scale tool.

   Scale Cage
      Editable bounding box for scaling control points.

Transform
   Combined tool for translating, rotating, and scaling.
Annotate </interface/annotate_tool>
   Draw free-hand annotations.
Measure </editors/3dview/toolbar/measure>
   Measure distances in the scene.
Shear </modeling/meshes/editing/mesh/transform/shear>
   Shear control points along a certain axis.
