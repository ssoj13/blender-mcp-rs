************
Introduction
************

Blender provides a variety of operators for editing meshes. They are available through the
menu and context menu of the 3D Viewport when in Edit Mode </editors/3dview/modes>.
Some menus can also be opened as a popover with a keyboard shortcut:

- Ctrl-V Vertex
- Ctrl-E Edge
- Ctrl-F Face

Some operators allow interactively transforming a mesh element or changing a value by
moving the mouse. These usually also support holding Ctrl to toggle snapping,
and Shift to change more slowly for better precision.
