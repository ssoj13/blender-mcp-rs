.. _bpy.ops.mesh.attribute_set:

*************
Set Attribute
*************

Opens a pop-up window showing the name of the active attribute
as well as the value of that attribute for the active element (vertex/edge/face).
From there, you can change the value to apply it to all selected elements.

The "active" attribute is the one last selected in the
Data </modeling/meshes/properties/object_data> tab of the /editors/properties_editor editor.
It could be a UV Map <uv-maps-panel>,
a Color Attribute <modeling-meshes-properties-object_data-color-attributes>,
or a generic Attribute </modeling/geometry_nodes/attributes_reference>.

**Seealso:**

   Attribute values can be viewed in the /editors/spreadsheet editor.
