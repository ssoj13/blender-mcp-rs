.. _bpy.types.GeometryNodeInstanceTransform:

***********************
Instance Transform Node
***********************

The *Instance Transform* outputs the Transformation Matrix of each top-level instance in the
local space of the modifier object.

The /modeling/geometry_nodes/instances page contains more information about geometry instances.

Inputs
======

This node has no inputs.

Outputs
=======

Transformation
   Matrix that indicates the Transformation of each top-level instance.
