*********************
Transpose Matrix Node
*********************

The *Transpose Matrix* node flips a matrix over its diagonal.

**Seealso:**

   `Transpose <https://en.wikipedia.org/wiki/Transpose>`__ on Wikipedia.

Inputs
======

Matrix
   The matrix to be transposed.

Outputs
=======

Matrix
   The transposed matrix.
