**********************
Combine Transform Node
**********************

The *Combine Transform* node combines a translation vector,
a rotation vector, and a scale vector into a Transformation Matrix.

Inputs
======

Translation
   The translation vector.
Rotation
   The rotation vector.
Scale
   The scale vector.

Outputs
=======

Transform
   The combined transformation matrix.
