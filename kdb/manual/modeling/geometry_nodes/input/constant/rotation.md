*************
Rotation Node
*************

The *Rotation* input creates a rotation from euler rotation values.

Inputs
======

This node has no inputs.

Properties
==========

X, Y, Z
   The amount of rotation about each axes.

Output
======

Rotation
   Standard rotation output.
