*****************
Editing Modifiers
*****************

Operators for working with an object's /modeling/modifiers/index.

.. _bpy.ops.object.modifier_add:

Add Modifier
============

Opens a menu with a list of modifiers, selecting a modifier will add it to the bottom of modifier-stack.

.. _bpy.ops.object.modifiers_copy_to_selected:

Copy Modifiers to Selected Objects
==================================

Copies all modifiers from the Active object to the other selected objects.

.. _bpy.ops.object.modifiers_clear:

Clear Object Modifiers
======================

Deletes all modifiers from the selected objects.
