***********
Collections
***********

Flow
   If set, only objects in the specified Collection
   will be allowed to act as /physics/fluid/type/flow objects in this domain.
Effector
   If set, only objects in the specified Collection
   will be allowed to act as /physics/fluid/type/effector objects in this domain.
