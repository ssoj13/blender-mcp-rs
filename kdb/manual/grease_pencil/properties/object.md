Visibility
==========

.. _bpy.types.Object.use_grease_pencil_lights:

Use Light
   Enables the Grease Pencil object to be affected by lights.

   This property affects the whole object, for more control with lights you can enable or disable
   the use of lights by layers. See Layers </grease_pencil/properties/layers> for more information.

**Seealso:**

   There are several other general visibility </scene_layout/object/properties/visibility> properties.
