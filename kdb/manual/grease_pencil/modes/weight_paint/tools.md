******************
Weight Paint Tools
******************

For Grease Pencil Weight Paint modes each brush type is exposed as a tool,
the brush can be changed in the Tool Settings.
See Brush </grease_pencil/modes/weight_paint/tool_settings/brush> for more information.

Brush
   Tool to use for any of the weight paint brushes <brushes>.

Annotate <tool-annotate-freehand>
   Draw free-hand annotation.

   Annotate Line
      Draw straight line annotation.
   Annotate Polygon
      Draw a polygon annotation.
   Annotate Eraser
      Erase previous drawn annotations.
