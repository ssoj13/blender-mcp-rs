.. _gpencil_draw-toolbar-index:

*************
Drawing Tools
*************

Cursor
   Change the location of the 3D Cursor.

Brush </grease_pencil/modes/draw/tools/brush>
   Tool to use for any of the drawing brushes </grease_pencil/modes/draw/brushes/draw>.

Erase <tool-grease-pencil-draw-erase>
   Erase strokes.

Fill <tool-grease-pencil-draw-fill>
   Automatic fill closed strokes areas.

Box <tool-grease-pencil-draw-box>
   Draw rectangular shapes.

   Circle
      Draw oval shapes.

   Line
      Draw straight lines.

   Polyline
      Draw straight multiple lines.

   Arc
      Draw simple arcs.

   Curve
      Draw complex Bézier style curves.

Trim <tool-grease-pencil-draw-trim>
   Cut strokes in between others.

Eyedropper <tool-grease-pencil-draw-eyedropper>
   Eyedropper to create new materials or palette color based on sampled colors in the 3D Viewport.

Interpolate <tool-grease-pencil-draw-interpolate> Ctrl-E
   Automatically create a breakdown keyframe between two normal keyframes.
