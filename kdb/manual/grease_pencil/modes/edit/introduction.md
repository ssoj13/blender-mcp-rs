************
Introduction
************

Blender provides a variety of tools for editing Grease Pencil strokes.
These are tools used to add, duplicate, move and delete elements.

**Note:**

   Editing multiple Grease Pencil objects at once is currently not supported.

Accessing Stroke Editing Tools
==============================

These are available through the different tools in the Toolbar,
the Stroke menu in the 3D Viewport header, and context menus in the 3D Viewport,
as well as individual shortcut keys.

Toolbar
-------

When you select a stroke and Tab into Edit Mode,
the Toolbar </grease_pencil/modes/edit/tools/index> changes from *Object Tools* to *Stroke editing Tools*.
These are only some of the stroke editing tools.

Menus
-----

The Stroke Menu </grease_pencil/modes/edit/stroke_menu> is located in the header.

Context Menu
------------

RMB brings up the complete Stroke Menu </grease_pencil/modes/edit/stroke_menu>.
