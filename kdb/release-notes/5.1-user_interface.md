# Blender 5.1: User Interface

## General
* Object data-block selectors now display the object type's icon. (blender/blender@b95374418c)
* Add icons to Set Handle Type menu, matching other similar menus. (blender/blender@537e264b70)
* Prepend asterisk ("* ") to labels which data has been modified and requires user attention. (blender/blender@4bccbe2b12)
* Search on key press in workspace add menu. (blender/blender@09ebf33bea)
* 'Save Modified Images' checkbox defaults to enabled when opening dialog. (blender/blender@6011489e66e47bfdf2e58ca6e9bc7c96943857cf)
* The size of the marker region has been reduced. (blender/blender@0ef54f8788d39b060d4fc25743b2c167435d37e3)
* Improved color picker hex color code auto-completion. (blender/blender@415d85d11aaad4d9e986c4cea1a60f24d602c579)
* Sidebar width is now persistent when toggling tabs. (blender/blender@2d536fbf66)
* Image Editor new shortcut Ctrl-1 and Shift-1 to get 1X zoom. (blender/blender@97527a5a7f)
* Can now hold Ctrl before area edge moving to start with snapping. (blender/blender@56a50e96d5)
* Chinese (and other languages) will no longer get tooltips with an extra ending periods. (blender/blender@305c55f2c2)
* IME (Chinese, Japanese, Korean, etc) will no longer start on numerical inputs. (blender/blender@b1ad4459d9)
* Editors now snap based on window increments not area sizes. (blender/blender@a2313d4e96)
* Image Editor zoom now shows value in the header, options in status bar, snaps, precision mode. (blender/blender@976453a237, blender/blender@65555b6b5f)
* Resizing editors now soft snaps at more places than just headers. (blender/blender@521293cb7a)
* Walk and Fly keymap items are now grouped together better. (blender/blender@2d8eb487c5)
* Panels contents are now a little cleaner when reduced to zero width. (blender/blender@a6958ccd87)
* Better tooltip positioning for items at the bottom of the window. (blender/blender@86554814a)
* Graph Editor icons have improved vertical centering. (blender/blender@afb6690591)
* When merging and docking areas, the source area that is closed is shown darkened. (blender/blender@29afe70120)
* Painting cursors now adjusted at small sizes to not obscure brush size indicator. (blender/blender@15f6beefae)
* TreeView now allows hovering Ctrl-C and -V to copy and paste. (blender/blender@b14ea0335c)
* Action slot name inputs now properly resize for long names. (blender/blender@a3f41c291a)
* Sidebar regions now remember their last width when minimized. (blender/blender@2d536fbf66)
* Language is now properly reset when selecting Load Factory Settings. (blender/blender@3e3e7fc409)
* Sidebars resized as the editor width decreases. (blender/blender@eeb2180123)
* Improved feedback when potentially overwriting a file. (blender/blender@540d70e341, blender/blender@dff22f04b6)

![Overwrite Feedback](images/SaveOverride.png)

* More UI lists are alphabetically sorted. (blender/blender@1882cd9811)
* Searching within Preferences! (blender/blender@0add7e5cd8)

![Preferences Search](images/PreferencesSearch.png)

* Improved curves details show in the Stats overlay. (blender/blender@5e96e4e8e5)
* Tooltips now stay still the mouse moves within elements. (blender/blender@ce4df145d3, blender/blender@1ab600f5e3)
* Confirmation dialog for "revert to saved preferences". (blender/blender@3d645e0efb)
* Improved scrolling into view for Tree views. (blender/blender@81a03b9928)
* Resizing panels items look more stable while resizing. (blender/blender@e269493cfa)
* Mouse cursor for area resizing no longer shown under Top Bar. (blender/blender@dbd5c4340c)
* Counts of objects are shown while dragging multiple items. (blender/blender@ab9bf68756)
* Color picker no longer overflows its bounds when the window is very small. (blender/blender@a35bf5a8d7)
* Quick Menu now always closes when selecting operators with accelerator keys. (blender/blender@46e89934f6)
* Improved "Remap users". (blender/blender@74956cb715)
* Hide dot-prefixed data blocks from search results (blender/blender@81f2113c71)
* Alphabetical sort option in Tree View. (blender/blender@b0eadb2b0a)
* Properties Visibility popover no longer covers category tabs. (blender/blender@6dfe6f34c8)
* Search menus to select a data-block to call an operator on now show the linking, library override or asset status icon as applicable. Same for the _Add > Collection Instance_ menu. (blender/blender@5d55e2a44d / blender/blender@6221ab1209)

* Quad View can now be resized by dragging the center point.
  (blender/blender@b5fd02b5cc)
* Quad View simplified by not showing duplicated overlays, status messages, gizmos.
  (blender/blender@5b3cd7cb06, blender/blender@43455ff155)

![Interpolation Icons](images/InterpolationIconColors.png)

* Selection icons now appear fully outlined in off state. (blender/blender@8463dda428)

## Asset Shelf

## Outliner
* Improved auto-scrolling of Outliner items when renaming. (blender/blender@0cbcd62f4e)


## Status Bar / Status Text
* Improved status bar display for `wm.radial_control` operator (e.g. changing brush size, strength, texture angle). (blender/blender@c71ff76821)
* All header status text is now centered while showing operator values. (blender/blender@6bfd6f5d13)
* Status bar no longer shows Z axis for 2D transforms. (blender/blender@f637093f5d)
* Improved Status Bar display when using the Interactive Add Object tools. (blender/blender@675905bd95)
* Removed status text jumps for commonly used operations, use fixed-width number padding and show extra precision when pressing shift. (blender/blender@34d612ca0f)

## Editors

### 3D Viewport
- It is now possible to customize the theme color of major grid lines. (blender/blender@d69338bb28)
- When using _Copy Objects_ without objects selected, a failure message shows and the clipboard isn't modified anymore. (blender/blender@450ccdc5eb)
- NDOF has a new "Drone" navigation mode.
  The camera will not change it's altitude when pushing the NDOF cap forward/backward.
  The altitude will change only according to up/down push.
  (blender/blender@0a3bfba4b59a633273814ced71666a217490b1dd)
- The `Overlays` panel was updated and the text related options were reorganized into a `Text` subpanel to accommodate for the new [performance text overlay](eevee.md#overlay). (blender/blender@90c3d56a0c53e08bb0aa78a1c0c34af43c7feb8f)

### Properties Editor
- The list of Shader AOVs now shows the matching socket icon (Color or Value). (blender/blender@cbd49755a1)

### Image Editor
- Keymap: Additional Ctrl+1 and Shift+1 convenience shortcuts to reset zoom to 1x. (blender/blender@97527a5a7f)

### Node Editors

#### Copy Paste

- Copy-paste between Blender instances is now possible, also works between different types of node editors. (blender/blender@e3ae31b49e534ae2e77413d5c7eae5dec7ca5cf8, blender/blender@3d522b7af8be75183c6cc6f318ce4495718322c6)
- When pasting nodes, they will automatically be snapped to the grid when snapping is enabled. (blender/blender@21acb3c0371c17d3a9aaffa2330ff2a5217e8ec7)
- Cut-paste is now supported, also between Blender instances (No shortcut assigned by default). (blender/blender@20ce68c5346f4cf1d33ea0f7ba946f7c88c76e12, blender/blender@99199bd193)

#### Swap Nodes

- Swap nodes operator allows swaping some zones while keeping sockets intact. (blender/blender@b6f33d971040eb521a86d6e7de562516baa39810)
- "Swap" nodes operator keeps sockets when switching between Separate and Combine Bundle nodes. (blender/blender@c5912f7c18a28ccfdc514ac79713fe21d8bdc6ab)
- "Swap" nodes operator can maintain data-block references. (blender/blender@69b82d911146a32dd23140aee14224422043e61e)

#### More

- Node Wrangler: New operator for moving selected nodes to the center of the node tree. (blender/blender@726a17d366)
- Theme: Node headers can be made semi-transparent again, using the node backdrop alpha value. (blender/blender@0e6023253e)
- Frame lables now use contrasting colors automatically. (blender/blender@0146930c32b88da9d553e070b6303acabce0f08b)
- View All (`Home`) and View Selected (`.`) now zoom in a bit closer. (blender/blender@eacd16a927)
- Node group interface tree-view supports multi-selection now. (blender/blender@42ac7b15b9f660bf1f699148b31aea59c71673d1)
- Float sockets can now have a subtype of **mass**. (blender/blender@452d50a3d594cf337ee0b42517f98dcee3645b3f)
- Geometry Nodes "Warning Propagation" label shortened to "Propagate" and added tooltip descriptions. (blender/blender@197aa96e49)
- "Use Nodes" toggle removed for Light objects, they now always use nodes. (blender/blender@74c44d8cc7)
- "Node" panel now has toggles to "Show Options", "Mute", placeholders in text inputs, and color settings are now aligned in a row. (blender/blender@8d1613abee)

### Spreadsheet

- Show Min Voxel for grids. (blender/blender@c03d9af63868ac204ab94ddaeca23dab9e426fc4)

### Asset Browser

- Searching uses fuzzy matching (blender/blender@3cbc9d158b)

### Preferences
#### Extensions
- Support for filtering extensions by repository
  (blender/blender@dbc505555857ee406d8c7034040b017f17d00f61)
- New "Update All" convenience button to install all available updates at once. (blender/blender@3b2f0b4516)
- Extensions that have available updates now display the version number (current → available), to see at a glance if it's a minor or major version update. (blender/blender@3b2f0b4516)

## Platforms

### Linux
* Client side decoration (CSD) support under Wayland,
  where Blender is responsible for drawing it's title-bar and borders.
  Only enabled for GNOME at the moment.
  (blender/blender@7032b785782628066f53df302bef5c39e0e51616)
* Blender application icon given better centering. (blender/blender@f7292f3f30)

### macOS
- The Cmd +/- keybind can now be used to zoom in/out the Animation Player window. (blender/blender@09e0d6b954)
- macOS now uses the same cursor sources as the other platforms, making it easier to maintain them. (blender/blender@8c88733c3f)
- iCloud Drive support was added to the File Browser (blender/blender@84e2c7e7cf06a10e52fc6e3cc84d1d56a092aa9f)

![macOS iCloud Drive Support](images/macos_icloud_support.png)

### Windows

* File Browser volumes can show USB icon. (blender/blender@0fe55b2382)
* File browser can show clouds storage volumes with specific icon. (blender/blender@733176db8b)
