# Blender 5.3: Grease Pencil

## Draw Mode

* Add support for selection in Draw Mode. The lasso selection tool is added. Only stroke selection is available. (blender/blender!161685)
* Added some (common) edit operators to Draw Mode. These include `Copy` & `Paste`, `Delete`, and transform operators (such as move, rotate and scale). There is a new `Stroke` menu that exposes the operators. (blender/blender!162890)
* Add an option to the Draw tool to create cyclic strokes. (blender/blender!157190)

## Carver Tool

* A new Carver tool was added to Draw Mode. This performs a proper boolean substraction. Both strokes & fills are cut along the lasso input. Holes are automatically created when needed. (blender/blender!144181)

## Fill Tool

* Add new multi-region filling to the Fill Tool. This allows for a path to be drawn with the mouse and all regions that the path crosses will be filled as one (blender/blender@623771bcbaa25695ecdb50b7fca83d095d096c29).

## Viewport

* The view can now be rolled when inside a camera (blender/blender!157869)
* New operator to reset the view roll (blender/blender!162225).
* The view can now be flipped when inside a camera (blender/blender!161274)
