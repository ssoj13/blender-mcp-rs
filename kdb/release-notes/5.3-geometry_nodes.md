# Blender 5.3: Geometry Nodes

* Drag-to-search visibility for Index Switch node (blender/blender@f5b26e16542ee56b21f4709a1b9b38861196f5ea)
* Various input nodes for Grease Pencil data (blender/blender@70898c55089dc3a45a23725fbb7b378ece4ee710)
* Link-drag-search for repeat zone iterations input (blender/blender@ea28033ce48418985893b071914976a18e8a777c)
* **Deactivate Voxels** node for removing active voxels from volume grids (blender/blender@3874a0bb0300d547ff9488b5f8cdf52b77988676)
* **Grid Topology Boolean** node for combining active grid voxels with boolean operations (blender/blender@9498c3a18c560bd7b8f591e7098b799fbef46d76)
* New and improved quadratic and cubic modes for grid sampling (blender/blender@3e38f8be15a4a8b837d518b218d19407ed9bc733)
* NURBS input nodes (blender/blender@8be98e47d75100674a28df7445ac74542ffcf13d)
* "Miter Scale" option for *Curve to Mesh* node (blender/blender@b1c96afb78a6)
* New **Rasterize Points** node for converting points to grids using rasterization (blender/blender@83397820).
* New **Get Vector Component** node to get the x, y or z component by an integer index (blender/blender@216b62e05c631930b1b39ca6b1f7f5ed2f0907be).
* **Preserve Normals** option for *Realize Instances* node for instances with negative transform determinant (blender/blender@970e052580a0ba1fb28a4416d8f15187eb5a1c3a).
* New **Combine List** node (blender/blender@cfc10639fb26f5ecbb426eeff8cff2f4c1e8ccef).
* **Miter Scale** options for *Curve to Tube* node (blender/blender@222c2d501fab14b1c07db031c0022c00d5411835).
* New **Poisson Solver** node for solving Poisson equations on grids (blender/blender@e0f6bb4fb1d75907af2ad0d538a69cfd2adffbfb).
