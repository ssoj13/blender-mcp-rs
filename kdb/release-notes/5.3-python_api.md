# Blender 5.3: Python API

## Node Editor
- New [`NodeTreeInterface.root_panel`](https://docs.blender.org/api/5.3/bpy.types.NodeTreeInterface.html#bpy.types.NodeTreeInterface.root_panel)
  for retrieving the top-level panel in the hierarchy of node tree interface items.

## User Interface

- New [`UILayout.label_multiline()`](https://docs.blender.org/api/5.3/bpy.types.UILayout.html#bpy.types.UILayout.label_multiline)
  function to place labels that can automatically wrap to multiple lines.
- New ``auto_keymap`` argument for popups to optionally support key accelerators.

  - `WindowManager.invoke_popup`
    (blender/blender@a9beda8c0ff2c6026d4e601ebeb1c6148181f541).
  - `WindowManager.popover`
    (blender/blender@f4f16d48ea5b1a452ec6ddac6a79396086d374c7).
  - `WindowManager.call_panel`
    (blender/blender@e1a676b12b81ca58c76c833873343d6540fa048e).

## GPU

- A new `gpu.types.GPUStorageBuf` was added to create and manage Storage Buffers (blender/blender@fae3d71db804a569b5ee9bfab7650bd51f57172b).

## Window Manager

- Read-only access to the current undo stack has been added
  (`bpy.context.window_manager.undo_stack`).
  (blender/blender@ae71b519937e7a301ec19a9fd4b04cafda1dcb1c)
- New [`WindowManager.try_activate_rna_button()`](https://docs.blender.org/api/5.3/bpy.types.WindowManager.html#bpy.types.WindowManager.try_activate_rna_button)
function to activate UI buttons referencing RNA data.

## mathutils

- `KDTree` now supports 2D trees with a dimensions argument
  (blender/blender@e81d8ae45a76813d37b2bd7e204d1c4ae2ccfb2c).

## bpy.data

- The [`all_ids`](https://docs.blender.org/api/5.2/bpy.types.BlendData.html#bpy.types.BlendData.all_ids)
  collection property internal implementation hase been modified,
  which changes the order in which IDs are placed in this collection.
  The property's order is also now documented as internal implementation detail
  (i.e. scripts should not rely or make assumptions on it).
  See also:
  (blender/blender!162179, blender/blender@53ed639726b4cd1e34e4cd35467e7b1075c83d67).

## bpy.context

- `context.markers`: contains the relevant markers for the editor
  (blender/blender@3048200244b8acb082c5399bd8b2aab8170035dc).
  These are the scene markers, unless the context is an animation editor
  that's configured to show the legacy pose markers.

## Render Engine

- New `bl_write_viewport_depth`, to let the render engine write its own depth buffer in `view_draw`. (blender/blender#163684)

## Built-in Python modules

Library dependencies were updated, exposing new Python modules for both existing and new dependencies.
The following modules are now available for Python developers to use:

- `OpenEXR` - see [OpenEXR Python module documentation](https://openexr.com/en/latest/python.html).
- `opentimelineio` - see [OpenTimelineIO Python module documentation](https://opentimelineio.readthedocs.io/en/latest/api/python/opentimelineio.html).
