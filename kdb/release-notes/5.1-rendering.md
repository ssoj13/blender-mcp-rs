# Blender 5.1: Rendering

## Shader Nodes

### Raycast

The new Raycast node allows casting rays against the scene geometry. (blender/blender@f7f6bdac6e169adc155dd058e05565586667efb8, [Manual](https://docs.blender.org/manual/en/5.1/render/shader_nodes/input/raycast.html))

This allows for a wide variety of effects, including NPR stylization integrated with scene shading.

- Normal Map option to switch between OpenGL and DirectX conventions. (blender/blender!149200)
- Join Bundle node. (blender/blender@55d543814270a51d99a9d8d8fa00ec80ddbffd97)
- Vector Math node option for element-wise rounding. (blender/blender@3ac918debf9472275ffea8f5a017f32b12ae9395)

## OpenColorIO

OpenColorIO was updated to 2.5, and for configuration authors the following new attributes are supported. The bundled Blender configuration was also updated to make use of these. (blender/blender!151958)

- `interop_id` for identifying the color space and embedding in OpenEXR files.
- `icc_profile` to specify the ICC profile to be embedded when saving an image file.
