# Blender 5.3: User Interface

## General
- For arrows on number button, use modifier keys to adjust values with precision, similar to click drag (blender/blender@728c8624b362e5944cc131965dd4acaa55778285)
- On Linux Wayland, Blender windows are now drawn with rounded corners (blender/blender@e17742004bfa).
- Region collapse arrow now uses theme color (blender/blender@5cbbd562a189f12ee88960f0064b61c69dd430b5)
- Sidebar regions now supports search filter (blender/blender@3eaa7c4d960a76aca2a89617f945767c71ffb0e8)

## Widgets
- Labels can wrap to multiple lines now (blender/blender@eee95f8124). In Python, such labels can be placed using [`UILayout.label_multiline()`](https://docs.blender.org/api/5.3/bpy.types.UILayout.html#bpy.types.UILayout.label_multiline).
- Labels can have markdown formatting now (blender/blender@e8c146ed8e7061b664bd9de00437f15588fe7056).
- Ctrl mouse-wheel to scroll through the active value is possible again for search menu buttons. (blender/blender@47f6b41f8e)

## Icons
- New icons:
  - Sequencer strip and data, and updated strip duplicate icon. (blender/blender!160875)
  - I/O: `IMPORT_EXPORT`, to be used when a collection has both importers and exporters assigned. (blender/blender!162450)
- Add icons to the following:
  - File Browser context menu. (blender/blender@796fbeca99)
  - Asset Browser library and catalog menus. (blender/blender@ca6084f980)
  - "Delete" and "Duplicate" operators that were missing icons. (blender/blender@e78cb53426, blender/blender@8360731a9f, blender/blender@b207b277e3)
  - Copy/Paste icons to all relevant menus. (blender/blender@09bf85e8de)

## Tree & Grid Views
- Scroll to previous/next page with Page Up/Down keys and top/bottom pages with Home/End keys (blender/blender@cf17ed10204580279fe395d90466241cf6cb5133)

## Tooltips
- Increased delay from 500ms to 1 second. (blender/blender@6c9dd10c8a)
- Improved readability of the inactive/disabled reason in tooltips, by adding padding and removing the "Disabled:" prefix. (blender/blender!160977)

## Keymap
- Shift+A now opens Add Modifier menu in Strip Modifiers properties tab. (blender/blender@3ac7f1e9c9)
- Ctrl+X now cuts nodes (dissolve + copy). Dissolve was moved to Shift+X. (blender/blender@53f70d9a10)

## Theme
- Theme Space: Three properties have been removed, as they were barely or not used at all, simplifying theming. The properties are: `Title` (use Panel Title instead), `Header Text`, and `Header Text Highlight` (use editor's Text and Text Highlight instead). (blender/blender@c2a37974ac, blender/blender@f0617f45e2)
- Theme Editor: Compact layout for Bone Color Sets to fit more elements on screen. (blender/blender!161791)
- The "Playhead" theme (under Common>Animation) now allows to set a transparency value. This changes the transparency of the vertical line of the playhead making it possible to see keys behind it.

## Input Method Editor (IME)
- Text input for the text-editor, console, sequencer & 3D text now support IME.
  (blender/blender@c26f81641ae35a015d1aace362ca653e2f853312,
  blender/blender@63fa40151e3c5f7ab36446a8117cdde28e5b06ca)

## Editors
### 3D Viewport
- For *Sculpt Mode*, *Vertex Paint*, *Weight Paint*, and *Texture Paint*, the *Falloff* panel has been renamed to *Shape* and various options have been added to it. (blender/blender@74143fb470)
- Viewport compositor is now enabled by default for the startup file in the default 'Layout' workspace and is set to *Always*. (blender/blender@4a1da15854)

### Node Editor
- Highlight links through reroute nodes. (blender/blender@702c14c08ad0e8c2e106ca287e258568f15312e4)
- Reorder various entries to follow alphabetical order. (blender/blender@fc7cb3f5d033ec5a22ee3f35770828678fd87d05)
- Highlight editables labels on hover. (blender/blender@50d9df48e3c8b0314f446fd5cf0c7bfdf04f7a50)
- Support for disabling outputs through switch nodes (blender/blender@1edbfbd2e6fffedc1baeb7c7ce65f1f27e7a4e94)
- Show warnings in collapsed node headers (blender/blender@58f7fe2157a7)
- New Comment node supporting basic markdown (blender/blender@1a542e41319fda83acc6f993e6b8515e250e63c1)

### Outliner
- Operator in context menu to pack selected images (blender/blender@64939ff906)
- Scroll outliner view to the new added collection (blender/blender@e362cddd4cd51974aede1ae699e1b79f94f32a41)
- Enabling renaming for new collection when it's added (blender/blender@d817626525bf22b0a7415d99422eeb53ce36c5b0)
- Append new collection as child of active collection or in same hierarchy of active object (blender/blender@82024c6ded4479948f7dd5d9e4f1cd2e87b227ff)
- Hide unselected objects in outliner with `Shift + H` (blender/blender@85fec7833550e0c84a1a118ac7e1741929fe07cb)
- New option "Expand on Focus" to uncollapse hierarchy during scroll to active element.  (blender/blender@159c5e8b971602156d37a5464e452b4731b4405a)
- New options to filter specific data from object hierarchy. (blender/blender@7037997c4d6e4186e6065b1276aec71027ccfa39)
- By default move selected object with hierarchy to target collection during drag-drop, use `shift + ctrl + LMB drag` to only move parent (blender/blender@aae30c8a134af6c2aa4060ade10acf4b81382d8e)
- "Holdout" and "Indirect Only" toggle for object tree element (blender/blender@4cf372ccdc50de7c57dcec1057b5445290c72a90)

### File Browser
- Theme: Items in the File Browser now follow the "List Item" theme settings, allowing for a lot more customization. (blender/blender!160853)
- New shortcuts: standard modifier-key shortcuts were added (not replaced, existing shortcuts are still there). (blender/blender!160120)

### Properties
- Make Strip tab use the new Strip icon, in orange (similar to Object). To better represent hierarchy and ownership, and make it stand out more. (blender/blender!160864)

### Animation
- Playback Controls: the "Active Keying Set" popover has been merged with the auto-keying popover, to save space. (blender/blender@24ae1c8d73)

### Assets
- Asset metadata fields now support multi-line text (blender/blender@f4eca1c3c3)

## Platforms

### macOS

- The Blender application icon no longer shows up in the Dock when running in background mode via the command line. (blender/blender@076a89d42ece9b93261feb784b62d9182fd3f0e0)
