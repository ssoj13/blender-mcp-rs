# Blender 5.1: Sculpt, Paint, Texture

* Various brushes and functionality that account for boundaries of a mesh (e.g. Smooth, Relax, Automasking) now properly handle strips of faces (blender/blender@d1bbef9369a62faa188cd7ce9c8fdbfb9b2c3f10).
* Texture Paint mode supports cancelling a stroke, bound to `Esc` by default (blender/blender@746c83811bfd343f24e517d9f703688acc8260e3).
* Property changes while in Texture Paint mode now creates undo steps when appropriate (blender/blender@0ac5946a89ce3210eec2904b0c9acbdff6c8680d).
* Debugging options for paint modes are now exposed in the UI when the 'Use Paint Debug' Developer Tools option is enabled (blender/blender@21b663bd4589286377d9cc8a167d979abae3ff51).
* Sampling colors in Vertex Paint mode now reads the mesh attribute data instead of the rendered viewport color (blender/blender@7178bae1d1befc71108aa25042237d80cfca800c).
* Color sampling in Sculpt mode now supports adding to the palette (blender/blender@7178bae1d1befc71108aa25042237d80cfca800c).
* Color sampling now accumulates color to achieve a blending effect for the brush or palette color (blender/blender@43cf72f1b85ee972d5a5b007c8c9a8115a3f385b).  
* A dedicated *Blur* brush and essential asset have been added to Sculpt mode (blender/blender@324ff177a36021e88c99e01c9db420db6e74a928).
* Sculpt mode now supports temporarily toggling to the *Mask* essential asset, bound to `Alt-Left Click` by default. Additionally, users can temporarily toggle mask erasing with `Ctrl-Alt-Left Click` (blender/blender@57871a572797f344ffc3d6c7ffa3f45aa1ad7a93, blender/blender@3ebdbb1ddebcc02333d8b692294bdc68d6634f10). 
* The `sculpt.face_set_change_visibility` operator now takes in an `active_face_set` parameter to allow indicating the selected face set id when using the Python API (blender/blender@ec7efb3887238793806f9f134957de36198bd76e). 
* When modifying face sets or mask data, users are warned if their current overlay settings prevent display of these attributes (blender/blender@e512c6b8ee13af6d2faf25ce781b7c52c9fddbcc).
