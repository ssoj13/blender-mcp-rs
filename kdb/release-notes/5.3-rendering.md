## 3D Gaussian Splats

Added support for 3D Gaussian Splats import and rendering (blender/blender!163102).

3D Gaussian splats are commonly used to reconstruct 3D scenes from photos or video.
They are are made up of many small, soft, transparent blobs that together can represent many types of geometry and shading.

![Gaussian Splat Example](images/render_gsplat.png)

### Point Cloud Data-Block

Gaussian splats are represented as point clouds, and for this a `Type` option
has been added to the PointCloud data-block. There are two types:

* `Points` - the point cloud behaves the same as before
* `3D Gaussian Splats` - the point cloud is rendered using the original Gaussian splat technique.
  In the future it will also affect behavior of transforming the point cloud object (for example, rigging).

There are extra attributes added to the PointCloud when they are used as 3D Gaussian splats:

* `scale` for the scale of the Gaussian splat, stored as Vector
* `rotation` Gaussian splat rotation, stored as Quaternion
* `radiance:base` the base (DC) radiance of the splats, followed by opacity and stored as 4D Vector
* `radiance:sh_{index}` for the coefficients of the bands >= 1 of the spherical harmonics, stored as Vector. The order is `<L=1 M=-1>`, `<L=1 M=0>`, `<L=1 M=1>`, `<L=2 M=-2>` ... where `L` is the band index, `M` is the basis function.

### Import

Import from PLY and SPZ files is supported.

For the PLY files the importer automatically detects whether the file represents a 3D Gaussian Splat based on the geometry and attributes. The typical convention for the coordinate system is `Z` as the Forward Axis, `-Y` as Up axis.

For the SPZ files all current versions of the format are supported (up to and including 4).
The importer automatically converts coordinate system to Blender's Up and Forward convention. However, it's been observed that not all software saves SPZ files in its convention, so manual adjustment might be required.

There is currently no export support.

### Geometry Nodes

* Added `Set Point Cloud Type` node (blender/blender!163530)
* Added `Import SPZ` node.
* The `Import PLY` node now detects whether the file represents a 3D Gaussian Splat and outputs it as a point cloud, otherwise it outputs a mesh. For this reason the output socket has been renamed to `Geometry` (blender/blender!163624)

### Rendering

All render engines, including Workbench, EEVEE, and Cycles, are able to render 3D Gaussian Splats.

By default, a 3D Gaussian Splat is rendered using an emissive shader. It is not required to create it explicitly.

![Default Shader](images/render_gsplat_default_material.png)

The `radiance` attribute provides access to the resolved radiance of the splat at the current shading point.

There is rudimentary support for making the splat relightable by replacing the `Emission` node with a hard surface BSDF such as `Diffuse BSDF`.

![Example of relit Gaussian Splat](images/render_gsplat_relight.png)

### Limitations

* Performance is not ideal.
* The current assumption is that the Gaussian splats are trained in sRGB space (which is what most authoring software uses).
* Rendering is not fully correct, as Cycles and EEVEE operate in linear space. This is mainly visible in areas with low opacity/high radiance.
* `Apply Transform` on a Gaussian splat does not work correctly as it does not yet handle the new scale, rotation and spherical harmonics attributes.
