# Blender 5.1: Cycles

## Performance

* Improved GPU rendering performance by 5-10% on various benchmark scenes. (blender/blender@4b34743b4e8a4988687bf9e6deff307464c7b95b)
* Improved CPU rendering performance on Windows, often around 5-20%. (blender/blender@1ebab9342b9b8d1671eb5dc7854f5d490f8a5a1c)
* For AMD GPUs, hardware ray-tracing is now enabled by default through HIP RT. (blender/blender@979af8dc5a6fcb502781cce49e839b80caed6fb1)

## Other features

* Normal Map node option to apply the normal map on either the smooth undisplaced mesh (for when there is a matching normal and displacement map), or on the displaced mesh (for modifying the normals in addition to displacement). (blender/blender#154031)
* With viewport rendering, the render result from Cycles and overlays from Blender line up better now when moving the camera. (blender/blender@305860f4e4d49d0ae54b1785c8ccfb0c4a04b7e3)
* Improved support for custom normals. (blender/blender!153836)
* Improved denoising quality with textured transparency and roughness. (blender/blender!154988)
