# Blender 5.3: Core

## Projects

A new project system has been added to Blender
(blender/blender@563b073381f0381d86ae91880c1f4da251b85025),
which makes Blender (optionally) aware of a larger context than just the currently open blend file,
and provides corresponding project-wide features.

The core concept is that each project has a root directory,
and all files under that directory are considered to be part of that project.
A project root directory is identified by a `.blender_project` directory inside the root directory,
which itself contains a project config file that is created and managed by Blender.

Blend files inside of a project then have access to project features and data.
For example, being able to use the new `project_root` variable in path templates.

In the future, projects will be expanded with more features to make them even more useful.

Note that the project system is purely opt-in and optional.

## Linked Packed IDs

### Changes to definition of direct/indirect linked packed ID
A linked packed ID is now considered directly linked if it's used by a local ID,
_or by any other packed ID also directly linked_
(blender/blender@bb67052433e2ff).

The latter part is new, as linked packed IDs dependencies are conceptually part of the packed data
(as they participate in the deep hash value), so if one is directly used,
all of its dependencies must also be considered as directly used.

### Changes to linked packed IDs writing
Now that there is a more useful and coherent definition of directly vs.
indirectly linked packed IDs, code writing linked data now only writes directly linked packed IDs
(blender/blender@bb67052433e2ff).

The indirectly linked ones are exclusively used by regular linked data from other libraries,
so writing them in the current blend-file is useless and only wastes space (and adds clutter).
This is especially useful in pipelines stacking several layers of linking in production files
(e.g. `assets.blend -> stage.blend -> shot_anim.blend -> shot_lighting.blend`).

## Undo

- Support for mixing global undo with other undo systems.

  Address a long standing limitation with undo: where edit-mode often
  prevented edits in other areas from being tracked by undo.

  (blender/blender@69f5d770c4f17b1688af1f9dceb12bb84d1591af)
