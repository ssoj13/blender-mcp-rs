# Blender 5.1: Compositor

## Added

- New **Mask To SDF** node to compute signed distance fields. (blender/blender@ee637f2098)

![Mask To SDF Node](images/compositorMaskToSDFNode.png)

- The **Index Switch** node is now supported. (blender/blender@33d8d2b6f2)
- New **Sequencer Strip Info** node to access the active strip's Start and End frames, Location, Rotation, and Scale properties. (blender/blender@a420f5974a)

<video src="../videos/sequencerStripInfoNode.mp4" title="Sequencer Strip Info Node" controls=""></video>

- The **Radial Tiling** node is now supported. (blender/blender@722310342f)
- The **Boolean**, **Integer**, and **Vector** Input nodes are now supported.
  (blender/blender@32d6bfc11a)

## Changed

- The **Mix** color mode of the **Mix** node now mixes the alpha as well.
  (blender/blender@2f745308ed)
  
  | Old | New |
  | --- | --- |
  | ![Old Mix Node Alpha](images/mixNodeAlphaOld.png) | ![New Mix Node Alpha](images/mixNodeAlphaNew.png) |  
  
- The **Relative To Pixel** node now works with non-single values. (blender/blender@a209c33c8a)
- The **Group Input** node is now faster in most cases. (blender/blender@e27fec950e)
- The **Glare**, **Directional Blur**, **Lens Distortion**, **Anti-Alias**, **Blur**, and
  **Vector Blur** nodes are now anywhere from 1.2x to 2x faster in some cases.
  (blender/blender@e362a3ea80)
- The **Image** and **File Output** nodes now read and write custom meta-data.
  (blender/blender@2dec178560)
- The **Group** node now performs implicit conversion for its inputs and outputs.
  (blender/blender@9aeb370ecc)
- The **File Output** node now allows specifying directories in item names. This was possible in
  older versions of Blender and the functionality is now restored. (blender/blender@e19dff1ef8)
- The **Movie Distortion** node correctly takes the image display window into consideration and thus
  would retains the image after Undistort -> Distort of vice versa. (blender/blender@0cf30bc6b3)
  
  | Old | New |
  | --- | --- |
  | ![Old Movie Distortion](images/movieDistortionOld.png) | ![New Movie Distortion](images/movieDistortionNew.png) |  
  
- The default compositor workspace now shows an image editor on top of a node editor (with backdrop disabled) (blender/blender@5d269e1ed5)
![Default Workspace](images/compositorDefaultWorkspace.webp)

## Removed
- 'Viewer Region' was removed. It was not working since 4.4 and will be re-introduced in the future. (blender/blender@a079875ffe)
