# Blender 5.1: Sequencer

## User Interface
### Timeline

- Blade tool now has a box gesture that allows for quick cuts, with support for "rippling", where future strips move 
  backwards to fill gaps. (blender/blender@4c7ecb80fccc95) The size and positioning of the box allows for fine control of this ripple behavior: if any part of the box lies on a channel, all strips on that channel will be included in the ripple operation as well. Hold <kbd>shift</kbd> to keep gaps and prevent rippling.  <br/>
      <video src="../videos/box-blade.mp4" title="Box Gesture for Blade" controls=""></video>
- Snapping to display bounds of a metastrip is now possible if snap to "Frame Range" is enabled. (blender/blender!151954)
- The speed control strip can now take negative values in "Multiply" mode to reverse footage. (blender/blender!152982)
- Retiming keys can now be completely hidden, with a new retiming icon that shows when the strip has retiming keys on it. (blender/blender!153683) <br/>
- Groups of selected strips can now be snapped to the playhead while maintaining their positions relative to each other with the new `keep_offset` property on the `sequencer.snap` operator. This behavior is enabled by default and can be invoked with <kbd>Shift+S</kbd>. (blender/blender!153735) The operator was also updated to allow snapping entire strips to either the left or right side of the playhead based on the position of the mouse cursor when the keybind is pressed (this may be adjusted afterwards in the redo panel). 

### Preview
- Strips can now snap to increments when scaling or rotating in the preview if <kbd>control</kbd> is held. (blender/blender!153109)

### Properties
- The strip time properties panel was cleaned up with improved names and extra information. Now left and right handle timeline positions are displayed clearly, as well as the underlying content start and end. See blender/blender!153012 for before/after comparison and rationale.

## Modifiers
- Strips inside or outside of meta strips can be assigned as mask modifier inputs.
  (blender/blender!148097)
- Compositor modifier can use the new **Sequencer Strip Info** node. (blender/blender@a420f5974a) <br/>
  <video src="../videos/sequencerStripInfoNode.mp4" title="Sequencer Strip Info Node" controls=""></video>
- Pitch modifier can be added to sound strips. Pitch can be adjusted in semitones or as direct numeric ratio. (blender/blender@d295416d61c)
 ![](images/vse_pitch_modifier.png)
- Echo modifier can be added to sound strips. Echo can be controlled with Delay, Feedback and Mix paramters. (blender/blender!150449)
 ![](images/vse_echo_modifier.png)
- The "Compositor" modifier can now be created together with a compositing node tree directly from the compositor. (blender/blender@b70f8ce818)

## Other
- Meta strips have audio volume setting to control volume of all sound strips within the meta. (blender/blender!149559)
- Render settings audio bitrate can be set to higher values than 384kb/s now (up to 2048kb/s, depending on audio codec limits). (blender/blender!151126)
- The progress bar is more useful when building proxies for multiple movie clips. (blender/blender@273c5e2e5a7bc0310e12ecd92ec9174a4875dd89)
- Soloing strips for the right-click select keymap is now <kbd>Shift+Left Mouse</kbd> by default. This allows for easier scrubbing of the entire edit with just <kbd>Left Mouse</kbd>. (blender/blender!153097)

## Python API
- Strip (`strip.`) time properties were renamed to improve clarity and make them easier to remember for scripting. 
  Old properties will still be available, but are deprecated (to be removed in 6.0, see blender/blender!153012). The full list of renames are as follows:
  * `frame_final_duration` -> `duration`
  * `frame_final_start` -> `left_handle`
  * `frame_final_end` -> `right_handle`
  * `frame_offset_start` -> `left_handle_offset`
  * `frame_offset_end` -> `right_handle_offset`
  * `frame_duration` -> `content_duration`
  * `frame_start` -> `content_start`
  * `animation_offset_start` -> `content_trim_start`
  * `animation_offset_end` -> `content_trim_end`

Note that "content" refers to the underlying source tied to a strip (e.g. a video file for a movie strip), which may be outside the bounds of the "strip" timeline extents. 

- A new `strip.content_end` was added for read-only access to the underlying strip content's ending frame (which may be beyond the right handle). (blender/blender!153012)
- The `keep_retiming` option for the `sequencer.retiming_segment_speed_set` operator has been removed, since segments would only get properly retimed if it was set to `true`. Setting its value to `false` merely added unwanted clamping, leading to buggy behavior. (blender/blender!153509)
- The changes above are also visible in the [Python API](python_api.md) section of the release notes.
