# Blender 5.2 LTS: Sculpt, Paint, Texture

## Sculpt

* New *Scene Project* brush. It allows displacing the sculpted object's vertices towards the surface of other objects in the scene, producing an effect similar to the *Shrinkwrap* modifier (blender/blender@f08e061cb75130a7af268921ee8cae6ce1f76e97).
* The *Add Primitive* (e.g. *Add Cube*, *Add Cone*, *Add Cylinder*, etc) tools are now available in Sculpt Mode (blender/blender@9c185de6bdfe4a5c0a97dccf8e76517cd423c8da). 
* The *Color Filter* tool in *Fill Mode* now uses the scene "unified" colors for its operations. (blender/blender@afc6d7a463e6bb01b54e207d18ba41c4eeb17c03
  * With the *Color Filter* tool active, clicking and releasing `LMB` applies the current color, `Ctrl-LMB` does the same with the secondary color. 
  * The current color can now be filled with any tool active with `Ctrl-X`, similar to the *Set Vertex Colors* operator in Vertex Paint.
* Enabling Dyntopo and switching back to Sculpt Mode with Dyntopo formerly enabled no longer asks for further user confirmation to do so (blender/blender@aae0f54d09bd13ae132b4bf00e28d81129aa20b1).
* The voxel remesher now interpolates vertex & corner attributes (e.g. color) instead of taking the value of the nearest point in the original mesh (blender/blender@c9ac62fd36aa9667cf124b9924b472c88833be0c). 

  This prevents scrambling of vertex painted meshes after repeated remeshing. The colors are much better preserved but a bit blurry:

## Paint

* Vertex Paint and Weight Paint now draw the brush cursor in 3D space, aligned to the underlying surface, when using the *Spherical* brush falloff (blender/blender@a5d2c1f635bef490a8bf5ec40287a1bdcf2b0346).
* Autosave support has been extended to Texture Paint (blender/blender@8ecebf0ce72820cdcc1627bc023808b517c7dff0).
