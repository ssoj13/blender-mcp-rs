# Blender 5.2 LTS: Rendering

## Render Output

* Saving render output can now be disabled. (blender/blender@342f37566f)
* Light/shadow linking can be easily copied to the selection (blender/blender!154382)

## Color Management

* Color space are now organized into menus, based on the `Family` attribute in OpenColorIO configurations. (blender/blender!151678)
* New input color spaces for Apple, ARRI, Blackmagic Design, Canon and Sony cameras. (blender/blender!155619)
* New color spaces for Adobe RGB, common gamma values, and wide gamut textures. (blender/blender!157702)

## Shader Nodes

### Time Node

A time node was added, which behaves the same as the one in geometry nodes. (blender/blender#156850)

### Thin Wall
Principled BSDF adds a new boolean input "Thin Wall". When this mode is enabled, the surface is considered a thin sheet. (blender/blender!157469)

### Subsurface Scattering

* The Random Walk radius scaling has been adjusted to match other renderers better (blender/blender!133848). To keep compatibility, older files are automatically converted to use Random Walk (Legacy) mode. There are also some [Cycles-specific changes](cycles.md#subsurface-scattering).
