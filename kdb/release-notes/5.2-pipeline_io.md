# Blender 5.2 LTS: Pipeline & I/O

## glTF

### Exporter

- New feature: Point Cloud export (blender/blender@153bade6e54aee7e591c996a6c2a55ae1eb37215)
- New feature: EXT_meshopt_compression and KHR_meshopt_compression export (blender/blender@3e6b5cae21b3723d41851b6c4b431f73887b3299)
- New feature: KHR_materials_iridescence extension export (blender/blender@0e94cdb502e9d2a07b5227d11ca1352355f84c4c)
- New feature: KHR_materials_dispersion extension export (blender/blender@ed7e9a7fe354ec45f2f4e8a560db07d104aea1ac)
- New feature: Hooks are now able to stop the export (blender/blender@6fb868797b298c3b45ffca7bc94f3ba7a5cb975f)
- New feature: Export official KHR primitive attributes (blender/blender@28e89be4edab94bf2fa92cba562eb36988ab6761)
- Performance: Use inline material when possible (blender/blender@49bff0770c42ba57fea3550f59e8a00eccaf87df)
- Performance: Animation export enhancement by disabling viewport (blender/blender@1a679af4f46b22fab0a6c3de2ce54968f4c9d306)
- Nodes are now sorted by name (blender/blender@6b583d742cdef234a3aa71b327bd03e3f393f888)
- Fix node group traversal (blender/blender@1edfbc415070b82506f513aa4fca6a9a1e9a5842)
- Fix crash reloading scripts (blender/blender@694b967967c2fc03705a49e6435180b253d84744)
- Fix Vertex Color export when used only in subset of materials (blender/blender@bfb768885d89630af55537ab877c3a96c40952ff)
- Enable UI filter for glTF Collections (action, variant, animation) (blender/blender@28bae3297d248c902690e37e101e5edc5133ee66)
- Lots of fixes on Animation Pointer (blender/blender@96c6a14a54d8ef5ace236d6912de0d881c699806)

### Importer

- New feature: Point Cloud import (blender/blender@d9412b1188f9a21df19ab07ccc88c33a37be17cc)
- New feature: Import official KHR primitive attributes (blender/blender@28e89be4edab94bf2fa92cba562eb36988ab6761)
- New feature: EXT_meshopt_compression and KHR_meshopt_compression export (blender/blender@3e6b5cae21b3723d41851b6c4b431f73887b3299)
- New feature: KHR_materials_iridescence extension import (blender/blender@0e94cdb502e9d2a07b5227d11ca1352355f84c4c)
- New feature: KHR_materials_dispersion extension import (blender/blender@ed7e9a7fe354ec45f2f4e8a560db07d104aea1ac)
- Fix importing multiple custom attributes that sometimes crash (blender/blender@74d3d06770403ef649e348b7a5139c54d96e9393)
- Lots of fixes on Animation Pointer (blender/blender@96c6a14a54d8ef5ace236d6912de0d881c699806)

## USD

- [Color space support](https://openusd.org/release/user_guides/color_user_guide.html). On import colors are converted to the blend-file working space. Export tags prims and image textures with their color space. (blender/blender!157196)
- Added new export option to control how frequently to save/flush the USD data to reduce peak memory usage (blender/blender@aabaffd311f11309cffa899e3349c3fe31bea130)
- Blender NURBS Surface objects are now exported (as mesh data) (blender/blender@1cdf15ae4f76eade8c1008812b61039509086d66)

## Images

- OpenEXR: Faster writing of half-precision (FP16) EXRs. (blender/blender!157874)

## Movies

- Stereoscopic metadata is exported. No need to post-process the video for correct playback in video players. (blender/blender@5635567dadc5875ba6ed44c4cdf1430cad3cc4ba)
- Panoramic camera metadata is exported. Only full equirectangle cameras are supported. (blender/blender@0d98bf9ff61cc58daa7debd886539982967ba8e9)

## Alembic

- Added support for importing non-animated and animated object visibility. Animations are imported as F-Curves. (blender/blender!157983, blender/blender!158321)
- Added support for importing animated camera data as F-Curves (blender/blender!158321)
- Original coordinates for subdivision meshes are now imported (blender/blender!159195)
- Topological changes for subdivision meshes are now properly detected (blender/beldner!159195)

## STL
- Added option how to eval (Viewport vs. Render) during export (blender/blender!157127).
