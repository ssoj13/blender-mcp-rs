# Blender 5.2 LTS: Motion Tracking

* Add "Move to Layer" operator for masks (blender/blender!138886)
  * Shortcut is `M` to be consistent with `Move to Layer` for objects
  * The shortcut to mute display of the footage has been moved to `Ctrl+H`
* Playback of high resolution footage in the movie clip editor
  is now faster on OpenGL (blender/blender!158624)
* Movie Clip "timecode files" functionality has been removed. Now building
  proxies just builds the proxies; `*.blen_tc` timecode files are no longer
  produced. (blender/blender!158840)
