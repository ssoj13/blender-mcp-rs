# Blender 5.3: Sculpt, Paint, Texture
* Unified paint setting toggles (e.g. size, strength, color) are now stored on a per-brush rather than a per-scene level, allowing individual brushes to opt-into using the scene-level settings. (blender/blender@6ecfe4e810ee635d9826a326ffe44b218e99bd7b)

## Mesh Painting & Sculpting
* Automasking is now supported in Vertex Paint and Weight Paint modes. The following options can be toggled and customized: (blender/blender@8704773557367b9955894409616bb13b9d5c064a)
  * Topology
  * Mesh Boundary
  * Cavity & Inverted Cavity
  * View Normal
  * Area Normal
* The *Front Face Falloff* option in Vertex Paint and Weight Paint has been deprecated in favor of the recently introduced Automasking settings. (blender/blender@ec438d7429e51b33ff8958da0c21def018d43835)

### Sculpt Mode
* Generic Mesh attributes (e.g. color attributes) are now interpolated and displayed when a Multires modifier is being used while in Sculpt Mode. (blender/blender@0932e7617164e93ad370ecb23a1d898f2f7ad32d)
* Textures are now displayed for meshes with a Multires modifier while in Sculpt Mode. (blender/blender@0ad469cb922264c2aa20cec128219410e23c2b2e)
* Sculpt Mode now has a *Transform Only Pivot* option to allow controlling the pivot placement with the transform gizmo without affecting the object geometry. (blender/blender@3b2ab96ff1d975ddb4f0f7f2e4e76e976fc36fac)
* Brushes with support for cube tips via the *Roundness* and *Tip Scale X* settings now display a rounded box cursor on the mesh. (blender/blender@1c2aa3581b37d89e72f5a3742e8316450b3f1dbb)
* The *Hardness*, *Auto-Smooth*, and *Spacing* brush settings can now be customized. (blender/blender@8f909f9abd205f26b43fcd59cb4e61614746a8e5)
  * As a result, the *Invert Pressure for Hardness* toggle has been removed from the UI and marked as deprecated. 

### Weight Paint
* The bundled essential Weight Paint brushes have been updated: (blender/blender@010b904e5ab8e8641bed2667b3e4328721e54c6a)
  * The default brush is now the "Add Weight" brush, which uses the "Add" blend mode, accumulation, and a low strength.
  * The existing "Paint" brush is renamed to "Set Weight" and now has a Constant falloff curve. This brush also has a new icon to distinguish it from the "Add Weight" brush.
  * The "Blur" brush has been changed to use accumulation with a low strength.
  * For all brushes, the stroke spacing has been changed to 5% to feel more responsive.
  * For all brushes which formerly used a Custom falloff curve that approximated a smoothstep function, the built-in "Smooth" curve is now used.
  * The brush asset shelf now shows by default.
* Weight Paint defaults have been updated: (blender/blender@010b904e5ab8e8641bed2667b3e4328721e54c6a)
  * Multi-Paint defaults to enabled
  * Auto-Normalize defaults to enabled
  * Mirror Vertex Groups defaults to enabled

### Texture Paint
* Undo and redo has been optimized for high resolution images and UDIMs. (blender/blender#162768)
* Efficient update of image textures and mipmaps is now supported in material draw mode and EEVEE. (blender/blender#161392)
