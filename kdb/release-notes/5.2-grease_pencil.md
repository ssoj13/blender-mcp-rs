# Blender 5.2 LTS: Grease Pencil

## General

* The "Move to Layer" operator now shows layer groups as menus and sub-menus of layers, matching the layer tree structure. Search also shows the path to the layer in groups. (blender/blender@d8d83f209a27a81baa05a9f515f3859995766525)
* Blend modes are added to vertex mode brushes, matching the existing modes used with meshes. (blender/blender@14926c9feeafc1c29a35c3b87733c44ede3ac857)
* Icons are used for Stroke, Fill, and Both stroke modes in the toolbar in Vertex Paint mode. (blender/blender@caed4743b2)
* `Shift + L` deselects strokes that are completely selected (blender/blender@66ee7f79c9)

## Draw Tool

The draw tool has a new setting to set the curve type of created curves, including `Bézier`, `Catmull-Rom`, or `NURBS` curves. The setting can be found in the `Post-Processing` section in the settings (blender/blender@ddbf8ac4378c9693554298b45b7c7d176dd1c042).

## Brush Assets

* Bundled brush assets have been updated. Changes include updated thumbnails, using the newly added material settings for `Dots` materials, and updated settings for the `Airbrush`, `Ink Pen Rough` and `Pencil Soft` brushes (blender/blender@7b9462e8693b41a4e0005187e40503265152ffbc).
  ![Updated bundled Grease Pencil brushes](images/gp_updated_bundled_brush_assets.png)
* New online textured brushes were added as part of the new ["online essentials" asset library](assets.md#online-essentials). To use the brushes in the asset shelf, ["Allow Online Access"](https://docs.blender.org/manual/en/latest/editors/preferences/system.html#bpy-types-preferencessystem-use-online-access) must be enabled in `System` > `Network` preferences (blender/blender-assets@9bf7bf5fb1e6f9bc0d1549262ad0d0b63d9d1344).
  ![New online Grease Pencil textured brushes](images/gp_added_online_textured_brush_assets.png)

## Fill Tool

An entirely new fill algorithm was added. The new `Delaunay` solver creates exact geometry from the boundary strokes. It has an automatic gap detection method, supports inverse filling, is zoom independent, and often runs much faster than the existing algorithm. The pixel-based flood fill algorithm is still accessible as an option under the `Advanced` tool settings panel, and the `Delaunay` algorithm is the new default (blender/blender@3702f7e714b438582170c2ef0ca53230d3850c59).

## Materials

* New placement settings for line materials using `Dots` and `Squares` were added, allowing materials to generate dots/squares at render time, which is orders of magnitude faster than e.g. subdividing the strokes using a modifier. There are three placement modes: `Count`, `Density`, and `Radius` (blender/blender@20e256add6d3e53e69f64f75e31c1f986957fe8f).
   * `Count`: Place a fixed number of dots. A value of 1 means that a single dot is placed per evaluated control point. This was the behavior prior to 5.2.
   * `Density`: Place a set number of dots per unit stroke length.
   * `Radius`: Place dots based on a percentage of the stroke radius. E.g. a setting of 100% will place touching dots along the stroke even when the stroke radius changes. A smaller radius will place more dots, and a larger radius will place fewer.
* Added randomization settings to the new placement options above. These allow the randomization of size, opacity, and color of the rendered dots/squares (blender/blender@135cf2d18d55f4e902635a141043cade29dffc9e).

## Eraser

* The "Default Eraser" setting is removed. Instead, when erasing from the draw tool, the last activated eraser brush is used. (blender/blender@8c22be8d89ec2aabcb16c153ba3aae2a816a521c)

## Line Art

* A new "Fill Strokes" option allows generated strokes to carry fill material, since now the fill is controlled by `fill_id` attribute on each curve instead of on the material itself. (blender/blender@f10745967b3ea6b609fde986a3fd61dcd18d0bc3)

## Import

* The SVG importer now exposes the `Scene Units` toggle that uses the scene units settings to scale the import accordingly (blender/blender@8055fde08b6d451b8251ad4fa42c9ac118491ef8).

## Export

* The PDF and SVG exporters now support exporting the corner types when `Uniform Width` is enabled. Note that the SVG format only supports one corner type per curve (blender/blender@4c373b81caca8275533d84df242ded7f8030629b).

## Python API

* Added two functions `layer.layer_masks.add` and `layer.layer_masks.remove` to add/remove layer masks (blender/blender@7ff9668c4939a0e24d1327236d85a876b13da032).
* Added `fill_id` and `hide_stroke` properties to strokes in the [high-level python API](https://docs.blender.org/api/5.2/bpy.types.GreasePencilDrawing.html#bpy.types.GreasePencilDrawing.strokes) (blender/blender@2c7b7056589eab53d3487db05adf9ae4db21e9b5).
