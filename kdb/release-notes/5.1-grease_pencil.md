# Blender 5.1: Grease Pencil

## General

- The "Move to Layer" menu now shows "Search...". (blender/blender@2a6faf6c7a)

## New Fill Workflow

Instead of creating and setting materials on strokes to enable/disable the fill, users can
now fill strokes using operators and tool settings. For example, the draw tool has a brush
option Stroke/Fill/Both that dictates how the curves are created and if they are filled or
not. If users want to add/remove the stroke/fill they can do so using dedicated
operators (e.g. in Edit Mode).

Additionally, fills can now have holes. Existing operators and tools are updated to account for holes
if necessary. There are new operators to select, create, join, and remove fills.

* The `Draw` tool and the `Primitive` tool have a setting to toggle between creating
   strokes, fills, or both. (blender/blender@7f1a798fc9)
  * A warning is displayed when trying to create a fully transparent stroke or fill. (blender/blender@7f1a798fc9)
* The `Fill` tool can create holes now if needed without relying on holdout materials. (blender/blender@7f1a798fc9)
* The `Delete` menu has two new entries (blender/blender@7f1a798fc9):
   * `Only Strokes`: Will delete only the selected strokes, without removing any fills. 
   * `Only Fills`: Will delete only the selected fills, without removing any strokes.
* Duplicating strokes will automatically separate fills into individual fills. (blender/blender@7f1a798fc9)
* New `Set Stroke Type` operator to set the stroke, fill or both on the selection. (blender/blender@7f1a798fc9)
* New `Join Fills` operator to join a set of strokes into the same fill. Inside strokes are
   automatically treated as holes (using the even-odd rule). (blender/blender@7f1a798fc9)
* New `Separate Fills` operator to separate strokes into new (individual) fills. (blender/blender@7f1a798fc9)
* New `Select Fill` operator to select all the stroke/points that are part of the same fill.
   Similar to `Select Linked`. (blender/blender@7f1a798fc9)
* New operator `Select` > `By Stroke Type` to select all the fills/strokes in a drawing.
* The `Trace Image` operator can create holes now if needed. (blender/blender@7f1a798fc9)
* The SVG importer can create holes. (blender/blender@7f1a798fc9)
* The PDF and SVG exporters can export fills with holes. (blender/blender@bdcae29683)
* When in Stroke Selection mode, selecting a stroke automatically selects the entire fill. This is intentional to make working with and transforming fills easier. (blender/blender@7f1a798fc9)
* Performance of the drawing tool has been improved when drawing very long strokes. Overall, tools like the sculpting tools, or rendering Grease Pencil should also benefit. (blender/blender@7f1a798fc9)

## Tools

- Allows `Make Parent` directly with a lattice object for lattice deform, this feature is previously available in prior to Blender 4.3 and was lost during grease pencil rewrite. (blender/blender@1a30058e75290b16b537a2ca1a9f87a4ab3d7a02)

## Python

- Added `LayerGroup.children` and `GreasePencil.root_nodes` collection properties. This makes it easier to iterate over the layer tree. Note that both of the iterators are in stack order, meaning bottom to top. (blender/blender@37d090254919905ab1599397a993a6c0b137f88b)

## Compatibility

With the changes to [Grease Pencil fills](#new-fill-workflow), some modifier setups might not work correctly. Specifically when using Geometry Nodes, the `Set Material` node with Grease Pencil materials will no longer fill Grease Pencil strokes. These setups will have to be slightly adjusted manually.

There are two new attributes that control the visual appearance of strokes:

* `hide_stroke` (Curve domain): Boolean value. Toggles the visibility of the stroke (both in the viewport
   and final render). Since the default value for boolean attributes is `false`, curves render
   their stroke by default.
* `fill_id` (Curve domain): This is a group ID. The value `0` indicates that the curve is not filled. Since this
   is the default value, **curves are not filled by default**. A value `!= 0` is a fill group ID. Curves
   with the same `fill_id` are triangulated together using a constrained delaunay
   triangulation (CDT) with holes (according to the even-odd rule).
   
**Example**: This setup converts a string to Grease Pencil fills. In 5.0 this needed a hack to get holes to work (by splitting characters into multiple pieces). In 5.1 the curves need a `fill_id` to get filled. The hack is no longer required.
