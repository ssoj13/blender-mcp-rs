# Blender 5.1: Assets

- Asset Libraries can now be individually disabled in Preferences. (blender/blender@ab2aa2512f)
- The catalogs hierarchy in the essentials library can no longer be edited. (blender/blender@4fe5946db3)

## Asset Shelf

- The asset catalog selector popup shows an improved/corrected label when there are no catalogs to display (blender/blender@d9b96d2cb8)
