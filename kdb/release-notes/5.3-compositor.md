# Blender 5.3: Compositor

## Added

- The compositor now uses an effects stack instead of a single compositor node group.
  (blender/blender@a45205780d)

  ![Scene Compositor Effects Stack](images/sceneCompositorEffectsStack.png)

- The interactive compositor now supports playback caching. (blender/blender@0f5669bbfb)

  <video src="../videos/compositorPlaybackCache.mp4" title="Compositor Playback Cache" controls=""></video>

- The compositor will now use the **Group Output** as a viewer if no viewer node exists.
  (blender/blender@de8811526d)

- The **Bundle Socket**, **Get Bundle Item**, **Store Bundle Item**, **Combine Bundle**, and
  **Separate Bundle** nodes are now supported. (blender/blender@b2a937ef91)

- The **Boolean Math** node is now supported. (blender/blender@e233152491)
- The **Compare** node is now supported. (blender/blender@19e0672d75)
- The **Float to Int** node is now supported. (blender/blender@150fb0cccd)
- The **Matrix SVD** node is now supported. (blender/blender@d89c56e21a)
- The **Integer Math** node is now supported. (blender/blender@fae91bee18)
- The **Hash Value** node is now supported. (blender/blender@f09119ea5c)
- The **Random Value** node is now supported. (blender/blender@7bb4c56c40)
- The **Is Viewport** node is now supported. (blender/blender@55b4559e6b)
- The **Import Text** node is now supported. (blender/blender@65ce9dd801)
- The **Bone Info** node is now supported. (blender/blender@2a704a6f0d)
- The **Combine Transform** and **Separate Transform** nodes are now supported.
  (blender/blender@d8016f9acf)

- A gizmo for the Translate Node was added (blender/blender@ca1ab1a3a7)

  <video src="../videos/CompositorTranslateGizmo.mp4" title="Compositor Playback Cache" controls=""></video>

## Changed

- **Playback** performance is up to 2x faster on GPU. (blender/blender@431235eb02)
- The default compositor node tree now uses a simple **Group Input** connected to a **Group
  Output** with no **Render Layers** node. (blender/blender@fa5c7fd6fd)
- The default file name of the **File Output** node is now `{blend_name}`, so rendered images will
  be named after the current blend file's name, instead of a hardcoded string. This is just the
  initial default value, the name can still be changed as usual. (blender/blender@f8cb4d4b5f)
- The compositor now renders scenes referenced inside node groups. (blender/blender@a939b4a6a2)

## Removed

- The **Render Result** is no longer updated during preview. (blender/blender@b11c155d7d)
