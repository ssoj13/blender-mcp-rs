# Blender 5.2 LTS: Virtual Reality

## VR Location Scouting

Introducing Location Scouting. A new VR feature allowing the user to block camera vantage points and assess the camera lens, focus and aperture while being immersed within the 3D environment. (blender/blender@0ee03419360ff9280f2dccf5b0febe4a7697087e)
