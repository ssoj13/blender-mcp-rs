# Blender 5.3: Pipeline & I/O

## USD

- Import: Add support for importing the UsdVolParticleField3DGaussianSplat schema i.e. Gaussian Splats (blender/blender@cfd6ba27e049ef734824f5771f6c3c4b726ab7f1)
- Export: Mesh export now supports writing normals matching Blender's original representation rather than converting them to corner/faceVarying first. (blender/blender@46d0a7ccd4187b064eb9bc4bf6bdf59cd1114b00)
- General: Support added for importing and exporting Matrix4d primvar attribute data (blender/blender@5ab643bb46a18b6db9f4f2e3cf455bae7659d020)

## Alembic

- Subdivision parameters from subdivision surface modifiers are now imported and exported. On import, a subdivision surface modifier is automatically added to subdivision meshes (blender/blender@f2a1c2848a1c19fcf275620dd77c926262de89fb)
- PointCloud objects are now exported (blender/blender@14a042845b0e94d49c000d095c13bc26412958e0)
- Curves velocities are now imported and exported (blender/blender@0729fe73e9f0086195f26c53f98a7bcfa3e01ebd)
- Arbitrary attributes on meshes, curves, and pointclouds, are now exported (blender/blender@19f60a40ff9208fddc013ff92f9882c38c75ec29)
