# Blender 5.1: Pipeline & I/O

## USD
- General: Support for authoring and loading the UsdUIAccessibilityAPI schema on all supported data-block types that allow Custom Properties. (blender/blender@54ce53ac4e96c0acaaa7d634500eff97047ab9b5, [Manual](https://docs.blender.org/manual/en/5.1/files/import_export/usd.html#usd-ui-accessibility))
- General: UsdPreviewSurface import and export improved to support transparency/translucency (blender/blender@fb2e777c4d95cf998646f40396a00ce3c3ebfc26)
- Export: Mesh export now writes indexed UV coordinates, which allows for UV island connectivity to be reconstructed by various other external applications. (blender/blender@1d1af1400a09b0a26fc41a9c6b6f6d03eccc6d22)
- Python hooks
  - Export: Added new `get_prim_map` API callable during `on_export`. Provides a mapping between Blender objects and the USD prims created for said objects.
  (blender/blender@61da6403beb116f542afd46b71c9020fc1ab5029)

## FBX
- FBX exporter now also exports shapekey normals, when exporting normals for the base mesh is enabled.
  This allows to solve some import issues with some game engines.
  (blender/blender!126491, blender/blender@0bc5373071).

## glTF

### Exporter
- Fix exporting not normalized lamp (blender/blender@275a8f95e518391d67c8cf25a82026a584d85d1c)
- Fix lamp temperature conversion (blender/blender@aedfaa51c7785437fcaaf0a05a1a63e15e37bdc1)
- Fix alpha animation with KHR_animation_pointer (blender/blender@fc4f9c668229ce5b1294853a05eada48fc001647)

### Importer
- Fix crash when GPU instancing attributes property does not exist (blender/blender@5ae2ce3597c9a7e36b6ecf84a2d53b4f30f387ed)

## Images
- Avif: New file format support. AVIF has better compression than other lossy file formats, supports HDR images and is widely supported in web browsers. (blender/blender!153540)
- OpenEXR: New lossless encoding option HTJ2K (high throughput JPEG 2000). It produces somewhat smaller files than other lossless
compression methods, but is very new and not widely supported yet by other software. (blender/blender!153292)
- JPEG 2000: Use multi-threading to speed up file saving. (blender/blender!152930)

## Video & Audio output

- Video encoding now allows "Custom" quality level by manually specified ffmpeg CRF value. (blender/blender!151264)
- Audio bitrate can be set to higher values than 384kb/s now (up to 2048kb/s, depending on audio codec limits). (blender/blender!151126)
