# Blender 5.0: Modeling & UV

## Modeling

### Modifiers

There are six new Geometry Nodes based modifiers.
(blender/blender@8ba63262bfba949d029c8fe67378e3bab4788c86)

- **Array**: Distributes the object along a line, circle, curve or with a custom transform. Also
  supports gizmos and randomization. The legacy array modifier is still available for now.
  <video src="../videos/array_modifier.mp4"
      title="New Array Modifier" width="600" controls=""></video>
- **Scatter on Surface**: Instances other objects on the surface. It features density as well as
  amount based sampling. The distribution can be controlled with an attribute and an image texture.
  Multiple of these modifiers can be chained to scatter different objects with different
  distributions.
  <video src="../videos/scatter_on_surface_modifier.mp4"
      title="New Scatter on Surface Modifier" width="600" controls=""></video>
- **Instance on Elements**: Creates instances on points, edges, faces or face corners.
  <video src="../videos/instance_on_elements_modifier.mp4"
      title="New Instance on Elements Modifier" width="600" controls=""></video>
- **Randomize Instances**: Adds additional randomization to instances created by other modifiers.
  <video src="../videos/randomize_transforms_modifier.mp4"
      title="New Randomize Transforms Modifier" width="600" controls=""></video>
- **Curve to Tube**: Creates a cylindrical mesh (or any custom shape) from a curve. It also
  supports round caps and generates a UV map.
  <video src="../videos/curve_to_tube_modifier.mp4"
      title="New Curve to Tube Modifier" width="600" controls=""></video>
- **Geometry Input**: Can be used at the beginning of the modifier stack to copy the final geometry of
  another object.
  <video src="../videos/geometry_input_modifier.mp4"
      title="New Geometry Input Modifier" width="600" controls=""></video>

Other changes to existing modifiers:

- Boolean Operation Solver label has been renamed from "Fast" to "Float"
  to better reflect its functionality.
  This change is applied consistently across the edit mode boolean operator,
  boolean modifier stack, and Python API.
  (blender/blender!141686)
- "Implicit sharing" is used for the storage of modifier bind data,
  significantly improving undo performance and decreasing memory usage
  (blender/blender@a08cd68f1eeb).

### Attributes

- Freestyle edge and face tags are now stored as generic attributes,
  with the names `freestyle_edge` and `freestyle_face`.
  The attributes will be propagated like all other boolean attributes.
  The `use_freestyle_mark` properties for this data on Mesh elements are removed;
  the attribute API should be used instead
  (blender/blender@b20ecee5556d).
  `Mesh` is not yet affected by this change.
- For curves, Grease Pencil, and point clouds, attributes no longer have a name length limit.
  Also, for Python API users, attribute references are no longer invalidated
  when adding or removing others
  (blender/blender@68759af51685, blender/blender@fa03c53d4a8b).

### Curves

- A new "Curve Data" panel in edit mode allows tweaking built-in curve attribute values
  (blender/blender@c59a1aedbfd4).

### Lattice

- New operator: "Lattice Deform Selected" accessible from the add menu.
  This adds a new lattice that deforms selected objects,
  by default the lattice is fitted to the selection bounds and oriented to match the active object.
  (blender/blender@c2319f8293d97775e4abccb64cf5701f02c0214b).

### Mesh

- Improve "Merge by Distance" behavior

  - Use a deterministic method of selecting the target vertex,
    picking the center-most vertex of a cluster with the lowest index as a tie breaker.
    (blender/blender@69e27b48557430e2992e8b5fa8e61337deb0edd2).
  - A new "Centroid" option moves vertices to the average location of all merged vertices
    (enabled by default).
    (blender/blender@93cc17dd720d5b4d24a8022851b5c8baa09ffcde).

- "Auto Merge" support for Symmetrize & Bevel operators
  (blender/blender@d0740846f40d6374dd340e8743b327434bf6e634),
  (blender/blender@a584197ab3580d4ec64a94f24ec4e11a91e707f8).

## UV

- UV Selection Improvements

  - Sync selection is now capable of selecting individual UV coordinates
    without having to select all UV's connected to a vertex.

    Common selection operations in the 3D viewport such as picking/box/lasso/circle select
    maintain the UV selection however some selection operations such as select-random will
    reset the UV selection, causing all UV's connected to selected vertices to become selected.

    Sync selection is now enabled by default.
    (blender/blender@62d72bd0b50814162290e133b84ba1265c705abc).

  - Use a shared selection for all UV maps, removing the per UV-map selection.
    When loading older files only the selection from the active UV-map is preserved.
    (blender/blender@f4308aa2d06e99f131e5eebbbcf9844d1106b78e).

  - Undo now stores UV selection settings such as UV select mode, sticky and sync-select.
    (blender/blender@37382b7c39d5c67cc851d8b464a821dcb64a480b),

- Add pack to custom region option to "Pack Islands" operator
  (blender/blender@a9a54c88b95945b96a1996e2dbb56e77c6f2761b).
- Add Minimum and Maximum to Align Vertically/Horizontally
  (blender/blender@9f28549fd4cee5dbbbebba37fe4239e0fdacf68f)
- Add "Arrange and align selected UV islands" operator
  (blender/blender@f7f4c154b66de6d3e1e591671734f672ce94f409)
- Add "Move Selected UV's on Axis" operator, accessible via num-pad keys
  (blender/blender@cfad6f4f25822c96a2ce57574b572336c65731ea)
- Convert the "Copy Mirror UV Coordinates" operator from Python to C++
  (blender/blender@919acbbf7f25f79b5a47720705f3a2d0d1dfc950)

## Python API / Compatibility Changes

- UV Sculpt `strength_curve` and `curve_preset` properties have been renamed to
  `curve_distance_falloff` and `curve_distance_falloff_preset`
  (blender/blender@0a72429ea8d1437ccaf7b7462ae919173ef179a2).
