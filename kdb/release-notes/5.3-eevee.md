### Fixes
- High sample count no longer produces banding on soft shadows. (blender/blender!161958)
- Sky textures now have full support for the sun disk. (blender/blender!163132)
- Sphere light probes are now captured using 32 bit float for more precise sun light extraction. (blender/blender!163132)
- Area lights no longer cause light leakage on the backs of objects under high exposure. (blender/blender!161262)

## Viewport

- Overlay: Anti-aliased mesh normal line drawing. (blender/blender!161025)
- Overlay: Anti-aliased mesh lines no longer break in x-ray mode. (blender/blender!160231)

## Vulkan

Vulkan backend is now default on Windows (not ARM) and Linux. Existing user preferences will not be migrated. (blender/blender!158803)

Vulkan minimum requirements has been lowered to Vulkan 1.1 and some GPU/driver features
have been made optional to support more devices. (blender/blender@e3a49cdebcc7692e495e3309804325771aea38d5)

## Hardware raytraced shadows in Workbench (Metal and Vulkan)

They can be enabled in the `Preferences > Viewport > Quality` settings.
The option will be shown as inactive if the current backend/GPU doesn't support hardware ray queries.
A new `gpu.capabilities.ray_query_support_get()` has been added to the Python API to support this UI functionality.

The visual results are the same as the stencil shadows implementation, but it provides a significant performance boost on modern hardware.
