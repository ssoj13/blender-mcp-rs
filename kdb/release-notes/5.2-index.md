## Compatibility

* Evaluated meshes created from scratch in Geometry Nodes will no longer end up with the same name as the object's original mesh (blender/blender@5e1e4de9d95d).
* The python API for `paint.eraser_brush` and `paint.eraser_brush_asset_reference` is removed as it is no longer used (blender/blender@8c22be8d89ec2aabcb16c153ba3aae2a816a521c).
* The Python API for accessing Geometry Nodes modifier properties has changed. For more information, see the Python API release notes (blender/blender@1561c1ea4ab6).
* Similar to 5.1, asset files with Geometry Nodes tools must be re-saved to be used properly in 5.2 (blender/blender@1561c1ea4ab6).
* Socket identifiers for the Compare and Random Value node changed (blender/blender@3a5cd7862bc1422188cdc7e6fb9ac3209077f479).
