# Blender 5.3: Sequencer

## Ripple Editing
- A new operator for ripple delete was added, which automatically moves all strips to the right of some selection back to the left when those selected strips are deleted. It may be invoked from the new cleaned up context menu or using the shortcut <kbd>Shift+X</kbd>. (blender/blender!160607)

## User Interface
- The default Video Editing app template was updated to include a new Compositing workspace and more vertical space for output/strip properties. It also moves playback controls to the Preview with the new scrubbing region to be more consistent with other video editors. All of these options are still fully customizable and can be overridden at any time. (blender/blender!158748)
- Compositor strip effects & transitions now also support node group inputs that are exposed in the properties UI, similar to how it was already
  done for compositor modifiers. (blender/blender!161026)
  <video width="300" src="../videos/vse_compositor_transition_inputs.mov" title="Compositor transition with inputs" controls=""></video> 
- Scene strips automatically adjust their content length when the scene that they point to updates its frame range. This replaces and deprecates the old "Update Scene Frame Range" operator which needed to be applied manually. (blender/blender!144146)
- "Sync Scene Time" was moved to the Playback popover, which has also been cleaned up with subsections. (blender/blender!161508)
- Strip icons were updated, and the strip properties tab is now orange (similar to object tab) to reflect its proper place in the data hierarchy. (blender/blender!160875), (blender/blender!160864)
- You can now drag and drop Mask, Scene, MovieClip, Text datablocks, text files, and colors from anywhere in Blender (e.g. outliner, ID pickers) to the sequencer. This works for both the sequencer timeline and the preview. (blender/blender!163221) (blender/blender!163440)
- A new user preference was added to allow changing the default length of strips with no inherent duration (color, text, etc). (blender/blender!163281)

### Timeline 

- Scene, Text, Mask and MovieClip strips now have thumbnails in the sequencer timeline. (blender/blender!151042) (blender/blender!160322)
  ![Scene strip thumbnails](images/vse_scene_thumbs.png)
- Added an overlay option to display thumbnails in the middle of strips (blender/blender!163382).
- Transformed handles and slipped strips are no longer clamped to their content bounds by default, to provide more flexibility and freedom when editing (but clamping can still be toggled by pressing `C` during operator invocation). To return to old industry-standard behavior, enable `Clamp Strips by Default` in the `Editing > Video Sequencer` preferences. (blender/blender!162118) <br> <img src="../images/vse-clamp-strips-by-default.png" width="500px">
- The timeline context menu was cleaned up and simplified in most contexts, with new icons and more sensible grouping of operators. (blender/blender!159498)
  - "Set Render Range to Selected" was added to the context menu as part of these changes.
- A new "Select All by Type" menu was added to bulk-select certain strip types in the timeline. In the process, the "Select Grouped" (Shift+G) operator options were cleaned up. (blender/blender!155826)
- Edge pan speed was adjusted to make it less sluggish when zoomed out, so that strips of a certain size on the screen will always pan at the same rate. (blender/blender!161288)
- The "Set Render Size" and "Scale/Stretch to Fit/Fill" operators are now supported for all non-sound strips (scene, movieclip, color, text, effect, on top of existing movie and image support). (blender/blender!161300), (blender/blender!162164)

### Performance
- Reduce playback frame drops around video cuts. (blender/blender!162451)
