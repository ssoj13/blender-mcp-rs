# Blender 5.0: Sculpt, Paint, Texture

## General
* The Sculpting template has been updated with some overlays now enabled by default. (blender/blender@d4167bfcd7)
* The *Multiresolution* modifier now has 'Conform Base' as an operation alongside 'Apply Base'. This moves the base mesh's vertices to their subdivided positions. (blender/blender@fee064e5242f1ff5c6188d835f2c141b24f41940, [Manual](https://docs.blender.org/manual/en/5.0/modeling/modifiers/generate/multiresolution.html#shape))

## Brushes
* Brush `size`, `strength` and `jitter` properties now have a customizable curve to change how tablet pen pressure affects each property during a brush stroke. There are also options to set these curves to a number of different presets. (blender/blender@5f8311f596a4ddb8fc03337f8bea07831116cd89, blender/blender@a40d484b1ab7b896eccbdd9d9e1884454bc2e8be)

## Python API / Compatibility Changes
See the [Python API](python_api.md#paint) section for a full list of breaking API changes.

* The unified brush settings (e.g. size, strength, color) are no longer shared across the entirety of a given scene, and are now mode specific. (blender/blender@4434a30d4042594ee2fbb95f4b9c46da38ca950a)

* Radial symmetry is now stored as a mesh property instead of a scene property, allowing for per-object radial symmetry settings. (blender/blender@d73b8dd4f3f5fb91cdf85311b98ff30faea14fb5)

* Brush and palette colors are stored in scene linear color space. The conversion of existing brushes may require manual fixing if they were used to store non-color data. For more information, see the [Color Management](color_management.md) section. (blender/blender@6aa11a304ca47f17912cb86fc8366cc4cecd581f)

* Brush size values now represent the diameter of the brush, not the radius of the brush. (blender/blender@8188dbd2466addb9ef503c13f0178ae171664ca8)

## Sculpt
* The *Grab*, *Snake Hook*, *Elastic Deform*, *Pose*, *Boundary*, *Thumb*, and *Rotate* brushes no longer show pressure sensitivity toggles. (blender/blender@0e2316c2bccbdd0a39d868790d065c7f3f3a76c6)

## Texture Paint
* The bundled essentials brushes have been updated to be grouped into catalogs. Additionally, the *Paint Pixel Art* and *Erase Pixel Art* brushes have been added. (blender/blender@06e391b5e47e2a42b78936f4293d8a12de51ff40)

## Undo
* Undo data for deformations is now compressed to be at least 2 times smaller overall. This can result in at least a 10% reduction in overall memory usage or can result in the ability to store more undo steps in memory. (blender/blender@8536fd12234649d98e4a57d72aeb322e107cf754)
* Operators in Sculpt mode that affect the base topology (e.g. Trim tools, Remesh) now report their memory usage to the general undo system. (blender/blender@919eb4bfe754a3ca479c570b611fde78c0d0194d)

## Weight Paint
* Weight values of less than 0.0001 are rounded to 0 when painting. (blender/blender@56c08fd5c46fd87b7c499febc85d0a30ae80b622)
* *Zero Weights* overlay setting defaults to *Active* instead of *None*. (blender/blender@eea22743c10d87e013018e679e706a89db10916a)
