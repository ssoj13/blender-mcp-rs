## Theme
Theme settings have changed significantly in Blender 5.0 to make creating custom themes easier. Numerous theme settings have been unified, and in total 300+ settings were removed. Because of that, custom themes from 4.5 LTS are expected to break in the new version. Users (and especially theme extension maintainers) are advised to read the [migration notes](migration/theme_migration.md) to learn about upgrading their themes.

- New theme settings:
  - **Outline Selected** for all widgets. Makes it possible to define a specific outline color for active elements, instead of using the same color for all states. (blender/blender@23fb5752ed)
  - **Panel Outline**, in the new *panel* section under User Interface. (blender/blender@db9ae93f02)
  - New settings to adjust **Curve** widgets (such as RGB Curves, Hue Correct, or Bevel custom profile curves). (blender/blender@b74e696acc)
  - New setting to adjust W axis color, used by quaternion and axis-angle F-Curves. (blender/blender@0fa67c3ea2)

- Theme settings for editor region have been unified in the new **Regions** panel:
  - Asset Shelf now follows a global style, instead of being per-editor. (blender/blender@11e729219a, blender/blender@fe0fe0a5ed)
  - *Theme Source List* was removed from animation editors, region colors are now unified in **Regions -> Channels** (blender/blender@fe0fe0a5ed)
  - Toolbar/Sidebar region styling settings were removed from all editors, region colors are now unified in **Regions -> Toolbar / Sidebars**. (blender/blender@fe0fe0a5ed)
  - Colors for scrubbing/markers regions were moved from each animation editor to a unified section under **Regions -> Scrubbing / Markers**. A new property has been added for the *Timestamp* color, which was previously controlled by the editors text color. (blender/blender@250384dd57)

- Theme settings for shared concepts have been unified in the new **Common** panel:
  - *Current Frame* color, which was unique to each animation editor (and 3D viewport) was moved into *Common -> Animation* and renamed to **Playhead**. (blender/blender@a459556ebd)
  - Preview Range & Keyframe colors were removed from individual editors, now they're unified in *Common -> Animation*. (blender/blender@39c066ee53, blender/blender@cb22938fe9)
  - Settings for channels, tracks, and channel groups were removed from individual editors, now they're unified in *Common -> Animation*. New unified **Channel** and **Selected Channel** colors also work on Movie Clip Editor (Dope Sheet mode) channels, which were previously hard-coded and not themeable. (blender/blender@a459556ebd, blender/blender@7f62d5d85e)
  - Settings for Bézier curve handles were removed from 3D Viewport, Graph Editor, Image/UV Editor, and Movie Clip Editor. They're now unified in **Common -> Curves**. (blender/blender@7d2b024151)

- Unified "User Interface" settings:
  - Sidebar tabs now follow the global styling of the tab widget. (blender/blender@e8735c3203)
  - Panels now follow a global style, instead of being per-editor. (blender/blender@7818082d02)
  - Move region text and title colors to Panel, and remove unused text highlight. (blender/blender@695a03d9f4)
  - Paint Curve color settings were removed from 3D Viewport and Image Editor, they use gizmo colors instead. (blender/blender@eca7056cfe)

- Removed settings:
  - Remove unused List styling from Nodes/Spreadsheet. (blender/blender@19c15e0218)
  - Remove "Navigation Bar" and "Execution Region" theme settings. (blender/blender@dd43eae0d3)
  - 19 unused settings were removed from various editors. (blender/blender@15567f597d)
  - "Face Dot Selected" color was removed from 3D Viewport and Image/UV Editor. Regular Face Selected color is used instead. (blender/blender@e0392599f8)
  - "Active Spline" color was removed from 3D Viewport. (blender/blender@1067112c11)

- Other:
  - Node Editor: Make node headers use the exact theme color, instead of a hardcoded mix. (blender/blender@2ea3cd2188)
  - Changes to geometry attribute colors in 3D Viewport: "Edge Bevel" and "Vertex Bevel" were combined into one **Bevel** property. "Freestyle Edge Mark" and "Freestyle Face Mark" were also combined into one **Freestyle**. The word "Edge" was removed from the remaining attributes - Crease, Sharp, and Seam. (blender/blender@28b97afda2)

## Node Editor

### Drawing

- Nodes look more flat with less of a drop-shadow.
  ![New Node Theme (right is new)](images/node_flat_theme.png)
- Group nodes are now draw a stack of nodes as indicator while getting rid of the icon in the node
  header. This makes them look more like built-in nodes. (blender/blender@916f0afd45)
  ![Group Node Indicator (right is new)](images/group_node_indicator.png)
- While group nodes can still be entered with the <kbd>tab</kbd> key, it's now possible to enter them with double click too.
- There are two new ways to leave a node group. One can either <kbd>double click</kbd> in empty space in the
  node editor or click on the breadcrumbs at the top of the editor. (blender/blender@7a01f736a5)
  ![Node Editor Breadcrumbs are now clickable](images/node_editor_breadcrumbs.png)
- The breadcrumbs also indicate whether a node group is linked or packed now.
  (blender/blender@e6a3328da73e719bae93b496438a7a5e0868119a)
- Collapsed nodes are drawn more rectangular instead of pill-shaped now. (blender/blender@23ad91ce5332e531a6f80d82478426d963b3129a)
  ![Collapsed Node Drawing](images/collapsed_node_drawing.png)
- The semantics of socket shapes has been changed. See the
  [blog](https://code.blender.org/2025/08/new-socket-shapes/) for more details (blender/blender@e72e049c84fea2105b44c6fcad4baa7c474b5f97)
- The label of node groups can be optional now, resulting in a cleaner UI in some cases
  (blender/blender@ef92735a951e74ca5741f86915e4a5dcb5d0e28e).
    <video src="../videos/optional_input_socket_labels.mp4"
        title="The labels of inputs can be disabled now" width="600" controls=""></video>
- Node tooltips show the `idname` of a node when Python tooltips are enabled. This is especially

  ![Color tooltips now show the actual color if possible](images/geometry_nodes_color_tooltip.png)
