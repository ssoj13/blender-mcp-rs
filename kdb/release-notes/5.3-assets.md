# Blender 5.3: Assets

## UI
- General asset operators are now also available in the "Asset" menu in the header (blender/blender@1807650fcd)
- For the _Essentials_ asset library, the _Unassigned_ catalog no longer shows up. It would always be empty anyways. (blender/blender@9812445b18)

## Asset Replacement Workflow for Online Libraries

Assets in online libraries can now be 'replaced' with versions for newer Blender versions. For example, an asset originally made for Blender 5.2 can be replaced with one for Blender 5.3. This works by saving the new version in another blend file, with `@b5_3` added to its name:

- `my_asset.blend`: the original asset for Blender 5.2.
- `my_asset@b5_3.blend`: the replacement for Blender 5.3.

When the [library listing is generated](https://docs.blender.org/manual/en/5.3/files/asset_libraries/remote_asset_libraries.html#creating-a-remote-asset-library), it will mark the assets from `my_asset.blend` for use until (but not including) Blender 5.3, and the assets in `my_asset@b5_3.blend` for use from 5.3 onwards.

This can be extended indefinitely: a third file `my_asset@b47_0.blend` will become available in Blender 47.0, and the assets in `my_asset@b5_3.blend` will then be used before that version.

## Access Token

Asset library servers can now require [authentication](https://docs.blender.org/manual/en/5.3/files/asset_libraries/remote_asset_libraries.html#access-token) to access and download their content.

## General
Assets now have a new optional `Webpage` meta-data field (blender/blender@90b85d5d17371e7056790f82da98d0df033c9c4f)
