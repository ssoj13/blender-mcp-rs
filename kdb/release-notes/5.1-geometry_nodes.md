# Blender 5.1: Geometry Nodes

## Volume Grids

The new volume grid system introduced in Blender 5.0 has been extended with a couple new nodes. The majority of the improvements were community contributed.

![New Grid Nodes](images/new_grid_nodes.png)

- The new **Cube Grid Topology** node allows creating grids from scratch where all voxels within a cube are activated. This is typically used with the existing Field to Grid node to potentially initialize multiple grids with the same topology (blender/blender@620ecf1324441b95ef64b80fd97f083ab72233ed).
- The new **Grid Dilate & Erode** node grows or shrinks the set of active voxels within a grid. It can be used to e.g. increase the size of the grid before advection (blender/blender@333b67cce0087c082c701d2736de3f5158a034e9).
- The new **Grid Mean** and **Grid Median** nodes allow averaging values in a grid in different ways (blender/blender@74e74e4c3611726b317e5d1972fd26226035002f).
- The *Set Grid Background* node has a new option to update the inactive voxel values too (blender/blender@3ee26a95b3519afbdea5f74cdefc1dc1426a5fb7).
  <video src="../videos/cube_grid_topology_erode_mean.mp4" title="Creating, eroding and smoothing a grid" controls=""></video>
- The new **Clip Grid** node deactives all voxels outside of a specific box in index space (blender/blender@6d95c9dd0f9c6ccf5ae3ab88b5e77e1f19b2ccd8).
- The new **Grid to Points** node creates a point cloud which has a point for each active voxel and tile. This is useful for building custom debugging utilities for grids (blender/blender@19119231cd3101a26cd058d03ccfc2e0b145722e).
  <video src="../videos/grid_clip_and_to_points.mp4" title="Clipping a grid and converting voxels to cubes" controls=""></video>


## String to Curves

The String to Curves node was improved in multiple ways, significantly improving its usefulness for building motion graphics templates. Most importantly, all inputs are now exposed as sockets, including the font in form of a new socket type.

![String to Curves](images/string_to_curves.png)

- The *String to Curves* node options have been promoted to input sockets (blender/blender@624f454e08b9e33464e662307ab3d34157b90030).
- There is a new **Font** socket (blender/blender@624f454e08b9e33464e662307ab3d34157b90030).
- Word index output in String to Curves node (blender/blender@dcef160d02256e3831690dd039d989609626a912).

<video src="../videos/string_to_curves.mp4" title="New options for the String to Curves node" controls=""></video>

## Bundles

There are new **Get Bundle Item** and **Store Bundle Item** nodes (blender/blender@b0341592207bd7f5c626616eeefcd747c1ae4545). The allow accessing and overriding individual elements in a bundle. Previously, one had to explicity separate a bundle and then construct it from scratch.

Besides being more convenient in some cases, these also introduce new functionality:
- The bundle item identifier does not have to be hardcoded but can be a computed string.
  ![Compute bundle item identifier](images/computed_bundle_item_identifier.png)
- They use "bundle paths". A bundle path is forward slash (`/`) separate list of bundle item keys which identifies an item in a potentially nested bundle.
  ![Bundle Path](images/bundle_path.png)


## Bone Info

The new **Bone Info** node allows accessing the pose of individual bones (blender/blender@5bf8fc30ccae9dbd43128d2d5e4f56ffd0d4268c).

## Node Tools

- A separate operator type is now registered for every node tool asset and local node tool. The operator idname can be customized in the "Options" popover (blender/blender@5411d2110c29).
  ![Custom node tool idname](images/node_tool_idname.png)
- **Node tools from previous versions must be opened and saved with 5.1**

## Miscellaneous

- The "Mix" color mode of the *Mix* node now mixes the alpha as well.
  (blender/blender@2f745308ed)
- The *Pack UV Islands* node now has inputs to define a custom pack region (blender/blender!147757).
  ![Pack UV Islands](images/pack_uv_islands_box.png)
- The *UV Unwrap* node now supports the Minimum stretch (SLIM) unwrap option and has a "No Flip" parameter (blender/blender@a86c05e50681).
  ![Minimum Stretch mode ein UV Unwrap node](images/uv_unwrap_minimum_stretch.png)
- New **Matrix SVD** node for Singular Value Decomposition of 3x3 matrices (blender/blender@7dbea2c51041416388b4dec8f73b1803d528aae6).
  ![Matrix SVD](images/matrix_svd.png)
- Support searching for node warnings with ctrl+F (blender/blender@6e463873f34f70e15ab951c5a5c88f459f0c5c34).
- The Fill Curve node has a new **Fill Rule** socket (blender/blender@866a62759a6ad2fecedd088383a903127b9092e4) matching the new setting in the Shape panel of curves, see also the Curves section in the Modeling & UV changelog.
