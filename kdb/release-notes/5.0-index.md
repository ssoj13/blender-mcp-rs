## Compatibility

* [Maximum Data-Blocks name length has been increased to 255 bytes](core.md#longer-data-block-names).
* [Removal of (Unsupported) Access to Runtime-Defined Properties Storage Data](python_api.md/#removal-of-unsupported-access-to-runtime-defined-properties-storage-data).
* [Big endian support has been removed](core.md#big-endian-support-removed).
* [Support for LZMA or LZO compressed point caches has been dropped](physics.md#point-caches)
* [Support for Intel Macs has been removed](https://devtalk.blender.org/t/deprecation-and-removal-of-macos-intel-builds-in-blender-5-0/38835)
* [Support for pre-2.50 animation has been dropped](animation_rigging.md#backward-compatibility).
* [Increase Minimum GPU requirements for Blender](https://devtalk.blender.org/t/system-requirements-for-blender-5-0/41457)
* [Cycles: The minimum supported NVIDIA compute capability is sm_50 now (~GeForce 900 cards)](cycles.md#gpu)
* [Cycles: Increased minimum GPU driver requirements for AMD HIP on Windows](cycles.md#gpu)
* [Blendfile Compression on saving is now enabled by default](core.md#other).
* [Theme API was rewritten and custom themes saved in older versions are not carried over](https://developer.blender.org/docs/release_notes/5.0/migration/theme_migration/)
