# Blender 5.0: Sequencer

## Sequencer Scene

The sequencer no longer uses the active scene in the window for its context. Instead it now uses the _Sequencer Scene_. This is a reference to a scene stored per workspace. In the Sequencer view there is now a Scene selector in the header (the property can also be found in the properties editor under the first category "Tool & Workspace Settings" > "Workspace" > "Sequencer Scene"). 

- This external reference makes the sequencer independent from the active scene, which is especially useful when working with scene strips and previewing the scenes they reference in the 3D Viewport. See the section about [scene time synchronization](#scene-time-synchronization) (blender/blender!140271).
- Note that, by default in 5.0, when creating new sequencer scenes (shown in the VSE sequencer view header), the active scene (shown in the Blender window header) will update to match the newly created sequencer scene. In this state, tweaking output properties such as resolution will properly affect the VSE edit. This is to ensure backwards compatible behavior for most simple use-cases. 
  - However, the sequencer scene of the workspace can differ from the active scene. In this case, tweaking output properties will affect the _active scene_, and not the _sequencer scene_. As mentioned above, having different sequencer scenes and active scenes is primarily useful when working with scene strips -- it isolates the VSE timeline edit to a separate scene within the same window, where scene strips in that edit can refer back to the active scene. Previously, one would have to open a new Blender window holding the VSE timeline edit to get the same result.
  - If the sequencer scene differs from the active scene, the Render menu will show new options for "Render Sequencer Image" /  "Render Sequencer Animation" on top of the normal scene render operators, allowing the user to specify which scene they'd like to render. Additionally, a toggle will appear in the Image Editor header for Render Results that allows swapping between scene and sequencer scene renders. (blender/blender!146934)

## Scene Time Synchronization

- When using scene strips in the timeline, there is now a new option to synchronize the active scene with the current scene strip. For example, this allows to dynamically switch between scenes by scrubbing or playing the timeline in the Sequencer. This option can be enabled by first showing the Footer of the Sequencer by going to "View" and checking "Playback Controls", and then in the footer checking "Sync Scene Time" (blender/blender!140271). 

## Scene Strips

- Scene assets now show up in the "Add" > "Scene" menu. These assets can be used to create reusable "scene templates". To create a scene asset, right-click the scene selector and select "Mark as Asset". Optionally save the file with the asset to an [asset library](https://docs.blender.org/manual/en/latest/files/asset_libraries/introduction.html#what-is-an-asset-library). In the "Add" menu, the [catalogs](https://docs.blender.org/manual/en/latest/files/asset_libraries/catalogs.html) are used to create sub-menus for better organization (blender/blender!141213).
- The "Add" > "Scene" > "New Scene" option got renamed to "Empty Scene". This no longer copies settings from the active scene strip, instead it always copies the settings from the active scene. (blender/blender!144069)

## Strip Modifiers

- A "Compositor" strip modifier was added (blender/blender@73fcbaf7c4). The modifier uses a compositing node tree that can be edited in the Compositor editor by changing the editor sub-type to "Sequencer". Note that currently VSE Compositor modifier is always using the CPU compositor.
  <video src="../videos/compositorModifierDemo.mp4" title="Compositor Modifier" controls=""></video>
- The Strip Modifier "Add" menu has been updated to use a pop-up menu which supports search, submenus, and can be extended to also list assets in the future (blender/blender!145981).
- The Strip Modifier UI has been updated to use panels that can be dragged and dropped (similar to object modifiers). The Mask Input settings are now in a subpanel. (blender/blender!145367). 
- All Strip Modifiers now feature icons. (blender/blender@491a39b0c6)

## Audio

- Sound strips can preserve audio pitch, when retiming is used.
  Pitch correction is on by default for newly created strips.
  (blender/blender!143347)


## User Interface
- Strip properties and strip modifiers are now moved to the properties editor (blender/blender!140395).
 ![](images/strip-properties-location.png)
- Adding strips with Shift+A drops them where your mouse is, and can be moved right away. This is enabled by default using the **Move Strips** property in
  the operator. (blender/blender!138382)
  - If this feature is used, and the mouse cursor lies outside of the VSE region when the add happens (e.g. when adding from File Browser popup), strips' starting positions are clamped to the sequencer region bounds so that they are immediately visible.  (blender/blender!141838)
- Text strips no longer limit the text string length to 512 bytes. (blender/blender!140733)
- Text strips display now have their bounding box (including for selection and snapping) around the text bounds, not at whole image size. 
  (blender/blender!140420)
- New footer region with playback and frame range controls. (blender/blender@35bcbad7e9)
- Handles for video and audio strips now clamp to the bounds of their underlying content by default. This can be toggled with the C key for old behavior.
  (blender/blender!134319) <br />

- Images can now be added in bulk from drag and drop or the file browser. (blender/blender!143974)
- A slip tool was added to the toolbar, making it possible to click and drag to perform slips. This can be useful for tablets where a keyboard is not handy. (blender/blender!143513)
- Strips/images can be copied and pasted in preview region. (blender/blender!143371)
- Histogram scope was improved for HDR content: display more values above 1.0, unlock horizontal/vertical zoom aspect while viewing it.
  (blender/blender!143537)
- "Insert Keyframe", "Insert Keyframe with Keying Set",  "Change Keying Set", "Clear Keyframes" and "Delete Keyframes" Operators are added to the VSE preview. (blender/blender!140107) (blender/blender!141106) (blender/blender!140385)
- Pie Menu on Drag can be used in VSE preview for adding keyframes. (blender/blender!144573)
- Waveform, RGB Parade and Vectorscope scopes have improved look: all the points are rendered individually, and retain a bit of
  original pixel color hue. (blender/blender!144867) <br />

- Select circle and lasso tools are added. (blender/blender!141422), (blender/blender!143391)
- Video Editing template has been updated. More streamlined UI hiding irrelevant elements, and the default scene is now called "Edit". (blender/blender@4bc240696e)

## Performance

- Waveform, Vectorscope of Overexposed overlay are much faster (they are fully done on the GPU now).
  (blender/blender!144867)
- Histogram scope is 2-6x faster, especially for large resolution / HDR content.
  (blender/blender!143175)

## Prefetching

- Prefetching is now turned on per default. The setting was moved from VSE preview area settings into timeline settings Cache tab. (blender/blender#139635)
- The prefetching area can now be controlled with the Preview range. (blender/blender#139635)
- Prefetching is now loop aware and will start to prefetch from the start frame when reaching the end. (blender/blender#139635)

## Changes and Removals
- Preference setting to use legacy pre-4.2 strip handle tweaking was removed in favor of the newer "Tweak Handles" system. (blender/blender!140031)
- Added a new "Duplicate Linked" operator that replaces the current "Duplicate" operator. Now, the "Duplicate" operator will also create duplicates of referenced IDs. This is currently the case for scene strips, movieclip strips and mask strips. This new behavior aligns better with the rest of Blender. (blender/blender!144138)
- Transform effect was removed (strip Transform section does the same thing). When reading existing files with Transform effect in them, the transformation will be combined into the strip transform, and the effect itself replaced with zero-size gaussian blur effect. (blender/blender!147003)
- Strip modifiers are now executed before strip transform is applied. This can alter the look of the strips a bit, especially if they are scaled up or down
  by large amounts. Strip masks continue to be applied in global/screen space, just like previously. (blender/blender!146181)

## Python API

- A new `strip.modifiers.active` property was added that gives access to the current active strip modifier (blender/blender!145367).
- See breaking changes to the python API [here](python_api.md#vse).
