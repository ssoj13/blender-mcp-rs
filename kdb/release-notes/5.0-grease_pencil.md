# Blender 5.0: Grease Pencil

## Editing

* A new "Curve Data" panel in edit mode allows tweaking built-in curve attribute values (blender/blender@c59a1aedbfd4).
* Added a new "Pen" tool in edit mode. This tool behaves similarly to the pen tool of the legacy curves object. See the [manual entry](https://docs.blender.org/manual/en/5.0/grease_pencil/modes/edit/tools/pen.html#tool-grease-pencil-edit-pen) for more details (blender/blender!142646).
* Interpolation tool now supports `Bézier` and `Catmull Rom` curve types (blender/blender!145683).
* Added new mode to the `Join` operator, this new mode (`Join Strokes`) is now default and behaves like the legacy Grease Pencil's Join operator (blender/blender!144666).

## Rendering

* Added support for motion blur (blender/blender@f7a000345201f259b94e754341d1b4925c25e8d1).
  Enable "Motion Blur" in the render settings and under the Grease Pencil render settings adjust the "Motion Blur Steps" for better quality. If the steps are set to 0, Grease Pencil will render without motion blur.

  > INFO: **Limitations**
  > When Grease Pencil is composited into the scene (e.g. behind meshes), we only do the compositing for the current frame and don't take the motion blur into account. This can lead to hard edges where Grease Pencil is e.g. occluded.
  > There is no motion blur in the viewport. 

* Improved the end cap rendering of cyclical strokes (blender/blender!143976).
* Added new corner types. Next to the existing "Round" corners there are now "Sharp" and "Flat" corners. New operators to set the corner types have been added. The corner types can be set per point and are accessible in the "Point" menus (blender/blender!143688).
  ![Corner Types (Round, Sharp, and Flat)](images/grease-pencil-corner-types.png)

## Overlay

* Bézier handle overlay now use the same colors as Curve objects (blender/blender!141524).

## Export

* Added support to export bézier, catmull-rom, and NURBS curve types to SVG. For now, this is only the case for strokes with uniform width (blender/blender@b056d3c85c).
