# Blender 5.0: Virtual Reality

## Vignette and Snap Turning
New features were added to the movement system in VR Scene Inspection (blender/blender@dde9d21b91c455f029b1aabf41d131bd1652a534):

- A vignette effect is added to the periphery of the screen. This appears only when moving.
- By default, snapping left / right on the right thumbstick will move the camera left and right by a discrete amount (previously, there was only continuous camera movement).

![VR Vignette](images/vr-vignette.png)


## Navigation Preferences and VR Session Settings
New options are now provided to fine tune camera movements in VR Scene Inspection:

- A new "VR Navigation" section under the "Navigation" tab in "Preferences". This includes the ability to adjust: vignette intensity, snap vs smooth turn, turn speed / amount, invert camera rotation.

![VR Navigation Preferences](images/xr_nav_preferences.png){ style="width:500px;" }

- Added a new option to control fly speed under VR Session Settings (in the N panel).

![Updated VR Session Settings](images/xr_nav_settings.png){ style="width:500px;" }

## Improvements to Teleportation
Miscellaneous quality of life improvements to teleportation in VR Scene Inspection (blender/blender@dde9d21b91c455f029b1aabf41d131bd1652a534):

- The teleportation raycast now arcs downward.
- Better affordances and visualization for when the teleportation raycast is successful / unsuccessful.
- If the teleportation arc does not hit an object, it will attempt to collide with the ground plane, making it easier to navigate around sparse scenes.
