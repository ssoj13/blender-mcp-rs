# Blender 5.0: Compositor

## Added

- The **Displace** node now has an interpolation option. (blender/blender@8b67050575)
- The compositing node tree is now its own data block, making it reusable across blend files.
  (blender/blender@bd61e69be5)
- The **Split** node now supports rotation. (blender/blender@8e966cceaa, blender/blender@9a33108afc)
  ![Split Rotation](images/splitRotationGizmo.gif)
- The **Alpha Over** node now supports the Disjoint and Conjoint Over operations.
  (blender/blender@0a152ddddf)
  ![Alpha Over Disjoint](images/alphaOverDisjoint.png)
- The **Translate**, **Scale**, **Transform**, **Rotate**, **Displace**, **Map UV**, and **Corner
  Pin** nodes now has an Extension mode option. (blender/blender@ac82b70b87)
  (blender/blender@00ed2030cb) (blender/blender@b709984df6) (blender/blender@ea94c0be22)
  (blender/blender@481c524734) (blender/blender@53832755ae) (blender/blender@570f44a059)
  ![Translate Node Extension Mode](images/translateNodeExtensionMode.png)
- The **Glare** node now has a **Sun Beams** mode, which is similar to the Sun Beams node but is
  much easier to use and get high quality results out of the box. (blender/blender@148eb703e1)

  | Image | Old Sun Beams Node | New Sun Beams Glare |
  | --- | --- | --- |
  | ![Original Image](images/sunBeamsOriginalImage.png) | ![Old Node](images/sunBeamsOldNode.png) | ![New Glare](images/sunBeamsGlare.png) |

  This mode also includes a new **Jitter** input, which speeds up the node execution at the expense
  of a more noisy/grainy output, which can also serve as a good control for a more artistic look.
  (blender/blender@b7742e6988)

  | Sun Beams With No Jitter | Sun Beams With Jitter (0.8) |
  | --- | --- |
  | 280ms | 70ms |
  | ![No Jitter](images/sunBeamsNoJitter.png) | ![0.8 Jitter](images/sunBeamsWithJitter.png) |

- A new **Convolve** node was added. (blender/blender@fdf95b53fa)

  ![Convolve Node](images/convolveNode.png)

- A new **Compositor** sequencer strip modifier was added. (blender/blender@73fcbaf7c4)

  <video src="../videos/compositorModifierDemo.mp4" title="Compositor Modifier" controls=""></video>

- A new **Kernel** option was added to the **Glare** now which convolves the highlights with the
  given kernel. (blender/blender@48ba7b7745)

- **Menu** sockets and **Switch Menu** node are now supported in the compositor.
  (blender/blender@a565e96f6c)

- An **Asset Shelf** was added to the compositor node editor(blender/blender@0a0dd4ca37)
- Built-in **assets** were added to the compositor (blender/blender@d4e90beab6)
  ![Asset Shelf](images/compositor_asset shelf.png)
  - **Chromatic Aberration**: simulates color fringing caused by lens chromatic aberration.
    <video src="../videos/CompositorChromaticAberration.mp4" title="Chromatic Aberration" controls=""></video>
  - **Sensor Noise**: Simulates the random pixel noise produced by a camera sensor.
  - Vignette: Darken edges.
    <video src="../videos/CompositorVignette.mp4" title="Vignette" controls=""></video>
  - **Sepia**: Applies brown tint to mimic vintage photo tones.
    <video src="../videos/CompositorSepia.mp4" title="Sepia" controls=""></video>
  - **Split Toning**: Tints highlights and shadows with different colors.
    <video src="../videos/CompositorSplitToning.mp4" title="Split Toning" controls=""></video>
  - **Tune Image**: Enhances contrast, color, clarity and sharpness.
    <video src="../videos/CompositorTuneImage.mp4" title="Tune Image" controls=""></video>
  - **Unsharp Mask**: Sharpen an image by increasing contrast along edges.
    <video src="../videos/CompositorUnsharpMask.mp4" title="Unsharp Mask" controls=""></video>
  - **Retime**: Changes offset, speed or steps of image sequences by changing the current scene frame.
  - **Separate Spherical:** converts a vector from Cartesian coordinates (X, Y, Z) into spherical coordinates (R, Φ, Θ) and outputs each component separately.
  - **Combine Spherical:** converts spherical coordinates (R, Φ, Θ) into a Cartesian vector (X, Y, Z).
  - **Separate Cylindrical:** converts a vector from Cartesian coordinates (X, Y, Z) into cylindrical coordinates (R, Φ, Z) and outputs each component separately.
  - **Combine Cylindrical:** converts cylindrical coordinates (R, Φ, Z) into a Cartesian vector (X, Y, Z).

- A new **Convert to Display** node was added. For most workflows it is recommended to use the native color management options in the scene and file output nodes. But for some advanced use cases the conversion can be manually performed in the compositorn typically combined with a Raw view transform in the scene. (blender/blender!145069)

## Changed

- Most nodes now have their matching input/output sockets inlined, similar to Geometry Nodes. (blender/blender@17e82ff030)
- The **Lens Distortion** node now maintains transparency. (blender/blender@3883a88d4e)

- The Low and Medium quality in the **Glare** node are now higher in quality, so they no longer miss
  small highlights and are stable across frames if the highlights change.
  (blender/blender@0a4b92678c)

  | Old | New |

  | <video src="../videos/glareQualityDownsampleOld.mp4" title="Old Behavior" controls=""></video> | <video src="../videos/glareQualityDownsampleNew.mp4" title="New Behavior" controls=""></video> |

- The **Map UV** node now supports Bilinear and Bicubic interpolation. (blender/blender@bc7412860a)
- 2D vector images now consume less memory and are faster to operate on.
  (blender/blender@0e304c813c)
- The Z Combine node was renamed to Depth Combine (blender/blender@b35971ad08)

  | Old | New |

- The **Composite** node was removed and replaced by a Group Output node whose first input needs to
  be a Color socket, and other inputs are ignored. (blender/blender@e34e6373b6)
  ![Group Output Node](images/compositorGroupOutputNode.png)
- The **File Output**, **Map UV**, **Corner Pin**, **Plane Track Deform**, and **Bokeh Blur** nodes
  now take translation into consideration and relevant inputs are clipped if translated.
  (blender/blender@c3688f7bb7)
- The **File Output** node was redesigned for a better user experience. (blender/blender@68dc278fe5)
  - It now supports dragging links to create a new input.
  - The final paths of the images are displayed in the UI to remove guess work.
  - The base path is now split into a Directory and a File Name.
  - Socket types are not set on the node and do not change.
  - Other UI improvements.
  <video src="../videos/redesignedFileOutputNode.mp4" title="Redesign File Output" controls=""></video>

- Most nodes now expose their menu options as inputs. (blender/blender@149a47ba57)
  (blender/blender@3b1faf7594) (blender/blender@e9638b4a0a)
- The **File Output** node now only appends the frame number to the image name when doing an
  animation render. Rendering through the command line always does an animation render, so no change
  of behavior is expected. Rendering using the `render.render()` operator when `animation=False`
  will see the change of behavior, but setting that to True and providing `start_frame` and
  `end_frame` should restore the old behavior. Finally, adding `####` manually in the name should
  substitute the frame number even in single renders. (blender/blender@b10d767c4e)
- The **Alpha Over** node input names were renamed to Background and Foreground.
  (blender/blender@9a2c7f334b)
- The **Size** input of the **Bokeh Blur** node is now defined in pixels.
  (blender/blender@5462d90fa8)
- The **Lift/Gamma/Gain** mode of the **Color Balance** node now operates in linear space.
  (blender/blender@a113121562)
- The **Lift** inputs were renamed to **Offset** in the **Color Correction** node.
  (blender/blender@f113af51ab)

## Removed

- The Dot output of the normal node was removed. Use Vector Math Dot Product node instead.
  (blender/blender@9e0e76f8ab)
- The Texture node was removed. Use the various procedural texturing nodes instead.
  (blender/blender@383c8860a2)
- "Use Nodes" in the node editor was removed (blender/blender@d88d4cc8ce)
- The **Composite** node was removed. Use a Group Output node instead. (blender/blender@e34e6373b6)
- The scale inputs of the **Displace** node were removed. (blender/blender@92be913a2a)

## Compatibility
Many nodes were [deprecated in Blender 4.5 LTS](../4.5/compositor.md#compatibility), and have been completely removed in Blender 5.0.

- The Gamma node was removed. Instead, use corresponding shader nodes. For instance, replace
  `CompositorNodeGamma` with `ShaderNodeGamma`. (blender/blender@d803ee4c79)
- Most node options that were deprecated in 4.5 are now removed. (blender/blender@498a2e5bcd)

See [migration notes](migration/compositor_migration.md) for more details about transitioning from 4.5 to 5.0.
