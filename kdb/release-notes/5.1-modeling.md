# Blender 5.1: Modeling & UV

## Modeling

### General

- Support for snapping to the face-center
  (blender/blender@090719e1eb86e9ae0c06d1749b552070922c989b).
- A new corrective flip normals boolean option enabled by default is available in the Apply Object Transform redo panel. 
  This allows normals to be automatically flipped when applying scale to objects with a negative scale
  (blender/blender@94b97412d1542e8071bb9158b6398b2be68e810c).

### Curves

- Update the curve fitting library with improved accuracy for
  freehand drawing of bezier curves and grease pencil.
  Fixes a solver bug and improves the refit method to produce curves that are a closer fit.
  (blender/blender@3935658dfd88ccb7f8309dc83ef9dfbbfff106ab,
  blender/blender@32614c4eaf0cdd184f56ea82948947d2e864ba33)
- Lasso/box/circle selection are supported in curves sculpt mode (blender/blender@77304f92546f9eb557d38a1ba315810bb0c7df34).
- Improved font filling for 3D text objects.
  Many modern fonts have overlapping outlines that previously caused large portions
  of characters to be incorrectly filled, often leaving holes or missing sections.
  A new fill algorithm is now the default for text objects,
  producing correct results with these fonts.
  Curves can also use this new filling algorithm.
  (blender/blender@7693dafb9a371bb09dadb650b28e788a9fe14652).

  ![Before](images/modeling_font_fill_broken.png)

  ![After](images/modeling_font_fill_fixed.png)

### Mesh

- The boolean Exact solver can be significantly (>35%) faster with many attributes,
  and the Manifold solver performance is slightly better in some situations too
  (blender/blender@b8ed4ba6dbc8, blender/blender@0cbedaff4df9).
- Added support for snapping (Ctrl) and precision (Shift) while using **Bevel**.
  (blender/blender@6ccc884ec40b49c98a9b4ac847e7d602cbd10796).
- Support for adjusting Vertex Slide settings
  (blender/blender@d896e2bc784ab391b7d7b73a8bbc3c358785c125).
- Polygon fill performance improvements for polygons with many sides.
  This resolves triangulation for N-gons freezing in certain cases.
  A ~5x speedup for concave N-gons is common, although results vary widely
  (blender/blender@1448cb28755705b5fa334c1ec5da18102a7afa29,
  blender/blender@fa9723b5df3ac59454d4b4c7066429fd1f381d96,
  blender/blender@9040f9eca8a68fb42b6f181786c8826dcbc284f3,
  blender/blender@2bc85a7af8eb390fa500895a0d29b3fe2247fe96).
- Delimiters for Loop & Ring Select Selection:
  Edge loop, edge ring, and face loop selection now support delimiters
  to control where selection stops. Boundary loop selection can stop at inner corners
  (boundary vertices with more than 3 edges) and outer corners, in addition to the existing
  n-gon stopping behavior. Edge ring selection supports stopping at seams, sharp edges,
  material boundaries, and can optionally step over n-gons with even side counts,
  Face loop selection supports stopping at seams, sharp edges, and material boundaries.
  These options are accessible from the redo panel after performing a selection in the viewport
  (blender/blender@e74fdc7c3f93ef7cba917267fc00931c70d7ea93,
  blender/blender@b905e04b81f3658dd2e6b7c016a672b113be905b,
  blender/blender@f4510ed5b2855dfe16bdf50ab8f5e8cb03b59376,
  blender/blender@39191aff199333f6bc3ee227d485ce131770d387,
  blender/blender@c3fabbb0133ef236e85f5e7fcb5dc28d336f9771).
