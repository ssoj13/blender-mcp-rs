# Blender 5.2 LTS: Compositor

## Added

- File Output node now has a **File Extension** checkbox that is independent of the 'File Extension'
  checkbox in the scene render settings. (blender/blender@3baa73145c)
- The depth of Grease Pencil objects is now reflected in the viewport compositor depth pass. This
  only works for EEVEE. (blender/blender@4dbf0b3325)

  <video src="../videos/greasePencilViewportCompositorDepthPass.mp4" title="Grease Pencil Depth Pass" controls=""></video>

- A new **Blank Image** node was added to return a new image of a given size and constant color.
  (blender/blender@7548e4936a)

  ![Blank Image node](images/blankImageNodeExample.png)

- Node gizmos now support auto keying. (blender/blender@4de3f61353) (blender/blender@e318cd056e)
  (blender/blender@dfefa70da9)

  <video src="../videos/compositorGizmoAutoKeying.mp4" title="Ellipse Mask gizmo auto-keying" controls=""></video>

- Node gizmos are now supported in the Image Editor. (blender/blender@c80f7a29a7)
- The **viewer gizmo** now follows the image display offset (blender/blender@baf05a1f16)

- The compositor now supports **Integer Vector** sockets. And they are now used instead of standard
  float vector sockets in the **Image Coordinates** node's **Pixel** output, the **Image Info**
  node's **Dimensions** and **Resolution** outputs, and the **Mask To SDF** node's **Nearest Pixel**
  output. (blender/blender@f49b33a081) (blender/blender@7e4656c7d5)

- A new **Frame** input was added to the **Stabilize 2D** node. (blender/blender@4ba88368d1)
- Added **Minimum** and **Maximum** outputs to the Levels node. (blender/blender@e08237bb8e)
- **Object** sockets and the **Active Camera**, **Camera Info**, **Input Object**, and **Object
  Info** nodes from Geometry nodes are now supported. (blender/blender@1d2ca9b15c)
  (blender/blender@e919a25441) (blender/blender@815059977b)
- Drag and drop objects from the outliner to the node editor is also supported (blender/blender@475ac16da5)
- The **Matrix** socket and **Matrix Math** nodes are now supported. (blender/blender@45d5533d8e)
  (blender/blender@446fa98c62)
- The **Rotation** socket and rotation nodes are now supported. (blender/blender@f1185c873b)
- The **String** socket and **String** nodes are now supported. (blender/blender@a241422362)
- The **Font** socket and the **Input Font** node are now supported. (blender/blender@d5fa560cc8)
- The **Warning** node is now supported. (blender/blender@5f2067df3e)
- A new **String To Image** node was added. (blender/blender@d5fa560cc8)

  ![String To Image node](images/stringToImageNode.png)

- The node editor now shows a render region when the backdrop is enabled. (blender/blender@6f0d4ac611)

  ![Backdrop render region](images/CompositorBackdropRenderRegion.webp)

- The compositor now supports lazy evaluation of Switch nodes whose condition is known statically,
  that is, not connected or connected directly to a Group Input socket. Lazy Evaluation means nodes
  that are not needed are not executed to save execution time. (blender/blender@e2c6c3d18d)

  | Static Lazy Evaluation ( Now Supported) | Dynamic Lazy Evaluation (Not Supported Yet) |
  | --- | --- |
  | ![Supported Lazy Evaluation](images/compositorStaticLazyEvaluationSupported.png) | ![Not Supported Lazy Evaluation](images/compositorStaticLazyEvaluationNotSupported.png) |

- Support for socket value inspection was added. (blender/blender@ffd88022c9)

  <video src="../videos/compositorSocketValueInspection.mp4" title="Socket Value Inspection" controls=""></video>

- The mask rasterizer now uses "Delaunay" tessellator by default which has robust support for
  overlapping regions. (blender/blender@a191d65b46)

- Added new assets:
  - **Film Grain**: Simulates the noise and behavior of analog film
  <video src="../videos/compositorFilmGrain.mp4" title="Film Grain" controls=""></video>
  - **3D to Screen Space:**: Transforms 3D coordinates from world to normalized camera space
  <video src="../videos/compositor3DtoScreen.mp4" title="3D to Screen Space" controls=""></video>
  - **Screen to 3D Space**: Given a depth and a normalized 2D vector, compute 3D coordinates in 3D space. This is the inverse transform of 3D to Screen space above.
  - **Transform and Project**: A generalized, lower level variation of 3D to Screen Space node that takes Transform and Projection as inputs instead of a Camera object to compute the 2D coordinates in screen space.
  - **Project with Depth**: A generalized, lower level variation of Screen to 3D space.

- Show pixel units for sockets representing pixel values. (blender/blender@a6df8a2cad)
- New masks can now be directly created from the Mask node. (blender/blender@0c7ff2c14c)

- Support for **Default Input Types** was added. (blender/blender@e96f40cdb5)

  <video src="../videos/compositorDefaultInputType.mp4" title="Default Input Types" controls=""></video>

## Changed

- The interactive compositor is now significantly more responsive. (blender/blender@6b0b0bedb9)
  (blender/blender@02273b966d) (blender/blender@426da77bbe) (blender/blender@8ba2d35cd3)

  | Old | New |
  | --- | --- |
  | <video src="../videos/oldCompositorViewerPerformance.mp4" title="Old" controls=""></video> | <video src="../videos/newCompositorViewerPerformance.mp4" title="New" controls=""></video> |

- The interactive compositor now supports animation playback. (blender/blender@0e812e7cec)
  (blender/blender@b1e2945ec4)

  <video src="../videos/compositorAnimationPlayback.mp4" title="Animation Playback" controls=""></video>

- The interactive compositor now relies on a more reliable mechanism for triggering execution. This
  has the following benefits (blender/blender@e30cb6f5d1):

  - Adding/adjusting a node that is not yet connected to the output will now no longer trigger a
    redundant execution.
  - Undo that is not related to the compositor node tree will now no longer trigger a redundant
    execution. This also means that operators will no longer block in the 3D viewport.
  - The compositor will properly execute on changes to cameras and objects referenced by the
    compositor.
  - Frame changes will no longer execute the compositor if it does not depend on time.

  <video src="../videos/interactiveCompositorExecutionTrigger.mp4" title="Interactive Compositor Execution Trigger" controls></video>

- **Anisotropic** sampling now works with **Transform** nodes and can be used for higher quality
  scaling down. Previously, it silently used Bi-Cubic sampling. (blender/blender@1df7f88e4a)


  | Old Anisotropic Scaling Down | New Anisotropic Scaling Down |
  | --- | --- |
  | ![Old Anisotropic Scaling Down](images/compositorAnisotropicScalingOld.png) | ![New Anisotropic Scaling Down](images/compositorAnisotropicScalingNew.png) |

- The **Group Output** node now displays the total execution time of the node tree.
  (blender/blender@58c25c54d6)

  ![Group Output Timing](images/compositorGroupOutputTotalExecutionTime.png)


- The **Distance Threshold** mode of the **Dilate/Erode** node is now orders of magnitude faster for
  relatively large sizes, and its execution time is now independent of the size or inset inputs.
  Finally, it no longer forces anti-aliasing when the inset input is less than 2.
  (blender/blender@fe30a328ee)
