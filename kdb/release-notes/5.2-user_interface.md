# Blender 5.2 LTS: User Interface

## General
* A new convenience operator was added to flip the X and Y render dimensions. Right-click on "Resolution X" or Y, "Swap Dimensions". (blender/blender@9155a65253)
* When saving a file with unsaved images, a new dialog box now asks if the user wants to also save the modified images. (blender/blender@37518ed6cc)
* A new user preference was added to allow specifying image saving behavior when saving a file with modified images. (blender/blender@bc57513da3)
* When using right click for selection, file and asset browsers will still spawn a context menu when right-clicking files/assets. (blender/blender@c8b32bd722)
* Aligned edges now don't join by default when resizing area. Instead use `Shift` key to move aligned edges together. (blender/blender@ca57a880af)

### Tree View
* Scroll the list when mouse is near edges of the view during dragdrop (blender/blender@8b1ec61c22)
* Invert sorting for both root and nested elements of the list (blender/blender@f98dcfeac9)
* Invert search filter to display items that don't match the search string (blender/blender@0d2d3a9115)
* Navigate in tree view and Grid view (asset shelf) with arrow keys (blender/blender@85b6e71d50)
* Bring active item into view by pressing numpad period key. Works in both tree and grid view (blender/blender@9e049a5aa3)

### Icons
* New:
  * `FILTER_FILLED`. To be used when filtering is active. Used in File Browser, Outliner, Spreadsheet, and Extensions. (blender/blender@97b0d68c1e)
  * `DOWNLOAD` and `DOWNLOAD_DONE`. For generic downloads. Used by the Download Asset(s) operators and online assets in menus. (blender/blender@35f2ed44d6, blender/blender@95239df338)
  * `PACKAGE_INDIRECT`. A dimmed version of `PACKAGE` used by indirectly used packed data-blocks. (blender/blender@5d7403c8ce23)
  * Status icons for warnings, errors, and information labels. `STATUS_INFO`, `STATUS_INFO_FILLED`, `STATUS_ERROR`, `STATUS_ERROR_FILLED`, `STATUS_WARNING`, `STATUS_WARNING_FILLED`. (blender/blender!161002)
* The "Set Parent To" menu now has icons for data/object type. (blender/blender@4bbd4be28f)

### Sidebar
* Sidebar tabs are now always visible. Previously, tabs would be hidden when only one tab was available. (blender/blender@f1d46c9eb1)
* Category tabs now supports showing in compact mode, i.e. icon or first two letters (blender/blender@fffd68ff37)
* Click drag to switch between category tabs (blender/blender@2bbd90ffa0)

### Widgets
* A new text-box widget was added that allows multi-line text input. (blender/blender@f19c08ae54)
* A new "link" widget type was added, to style buttons as links (blue, underline). The color can be customized via the theme. (blender/blender@0cc55f2c9b)
* Menus and popovers can now be panned using the middle mouse button, similar to other areas in Blender. (blender/blender@c4ae6be9bf)
* It is now possible to paste hex values directly into color widgets. (blender/blender@b2f14457ef)
* Sub-panels inside popovers can now be collapsed. (blender/blender@c31dcbc0fa)
* When text editing a number widget, the unit no longer is part of the selected text. Instead, a unit hint is displayed after the number typed in. (blender/blender@8cb6fc3034d)

### Tooltips
* When Developer Extras is enabled, the property's icon ID is shown in the tooltip. (blender/blender@f8e5fe8de7)

### Toolbar
* The order of Circle/Lasso Select in the toolbar was made consistent between editors. (blender/blender@d8bcb86dac)

### Keymap
* Framing active element is now possible with Mouse Button 4 as well by default, alongside Numpad dot/comma. (blender/blender@bbf1ac1b4a)

## Editors

### 3D Viewport
- Camera's now have a gizmo to adjust their orthographic scale
  (blender/blender@da6a3052b769dd5c183c0f4232fdaa9fbde37011)
- The Brush popover "Advanced" section in various paint modes has been reorganized and turned into a collapsable subpanel (blender/blender@b751b3664ff0bb08ce8d9c203c3c22ddb1113099)

### Image/UV Editor
- UV Grid overlay options are now visible in all image editor modes. (blender/blender@6ffa78ef64)

### Node Editor

- Grouping and Ungrouping:
  - "Make Group" operator now avoids type conversion of inputs with multiple connections and avoids duplicate output sockets (blender/blender@63fccca32d)
  - "Ungroup" operator now adds proxy input and converter nodes, to ensure the node behavior remains unchanged after ungrouping (blender/blender@b1a865b347)
    <video src="../videos/ungroup_proxy_nodes.mp4" title="Proxy input nodes when ungrouping" controls=""></video>
  - New "Implicit Conversion" nodes can be used to convert values to a fixed data type (blender/blender@5b8b780ff7)
- Input Nodes:
  - New constant input nodes have been added for Menu sockets and Font data blocks in all node editors (blender/blender@0eca88e118)
  - Boolean, Integer, and Vector input nodes have been added to the Shader Editor (blender/blender@defa2e3ddb)
  - Vector input nodes support 2D and 4D vectors (blender/blender@fbebd8998d)
    ![Vector and menu input nodes](images/vector_and_menu_input_nodes.png)
- Editing Nodes:
  - Affect all selected tree interface items when holding alt. (blender/blender@282352651fd754eaa62f6dcf99570a064ee7354f)
  - Multiple nodes can be resized at the same time now. (blender/blender@0c1526ca566e316f1d1ad512de1c08012d1c17af)
  - More renaming directly inside of nodes. (blender/blender@c38e67125ae85fbfbaf13313f6937554b636ce8e)
  - Support adding dynamic sockets directly in nodes. (blender/blender@d3a0d4ebf41a4c2498ce267d120c356bbe2be482)
    <video src="../videos/node_editing_improvements.mp4" title="Node editing improvements" controls=""></video>
- Float, Integer, Vector, and Integer Vector sockets now support Pixel subtype. (blender/blender@d6b0edf63b)
  ![Pixel subtype](images/pixel_subtype.png)
- Update evaluation on text-edit change in String input node. (blender/blender@52edaaa1f063b07d7b463f5cea1ea2cbef308e61)
  <video src="../videos/string_immediate_update_and_multiline.mp4" title="Immediate evaluation when string is changed" controls=""></video>
- The merge operator of node wrangler now supports integer math nodes (blender/blender@609ae726310)
- Linked node groups have been moved to a submenu in the add menu. (blender/blender@3a7652f7fabda581b92bc8d6510f873929b75f60)
- Add menu does not show indirectly linked groups anymore. (blender/blender@92ffc4dd8aef428e724d178983d4abe03463e440)
- World: When dropping an image into the World shading editor, an Environment Texture node will be created (instead of a regular Texture), which is more convenient for HDRI setups. (blender/blender@d17de0817a)
- AOVs are now searchable within the AOV Output node. (blender/blender@52d130012c)

### Outliner
- New "Scroll to Active" option to keep the view centered around the active object, making it easy to find in big scenes. It's enabled by default. (blender/blender@f0694d80bc)
- Display individual shape keys (blender/blender@efcd6c653f)
- Subpanels added to filter panel and removed the icon (blender/blender@d5c53f9cdb)

### Animation
- The `Mirror` menu for keys has been tweaked so it's easier to read. (blender/blender@292bbb87c8)

### Preferences
- Theme Editor: Small reorganization of color, text style, and user interface panels for easier editing. (blender/blender@74ed382748)
- After disabling _Allow Online Access_, the parts of Blender that needs internet access will present the choice to continue offline or allow internet access again. (blender/blender@5ea9d96980)

## Platforms

### Linux
- In Wayland, it's now possible to use key-shortcuts with non Latin layouts (such as Cyrillic).
  For this to work a second layout must be available that maps Latin characters (A-Z).
  This will be used as a fallback when keys from the active layout are not known.
  (blender/blender@eaf63a35ae0b526c0cf8358f4d30b74dfe47da43).
