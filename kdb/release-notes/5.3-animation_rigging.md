# Blender 5.3: Animation & Rigging

- "Align to Transform Orientation" operator is now available in Pose mode as well (blender/blender@7c00566f74).
- Added a new operator "Replace with Duplicate Action" (blender/blender@323d5a07588459b57e1284b15fc196d0cdd1b5e1).
- "Make Markers Local" was renamed to "Convert to Pose Markers" in the UI (blender/blender@ade68c48b65702469aef178981c000e5c3471b0c).
- When pasting poses (using `Ctrl+V` in Pose mode) the redo panel now has an influence slider so you can blend in the copied pose.
- Added a new operator to convert animation between rotation modes `anim.rotation_mode_convert` (blender/blender@db9fd84d4ee8cffddd437500091f6a5287b9c95f).
  - The operator can be found under "Object->Animation" and "Pose->Animation".
  - This operator is also called when using the Ctrl+R hotkey.
  - The old operator `pos.convert_rotation` from rigify has been deprecated.
  - The feature is also available from Python on objects and pose bones using the new `convert_rotation_mode` function.
- Added a new set of operators to copy/paste world space animation (blender/blender@b988d827b62936e6ce4a44f28125308a8e389fa6)
  - Can be found in the 3D viewport in the "Animation" tab on the right side.
  - Works on objects or bones
  - Will copy the scene range, or the preview range if that is used
  - Pasting to constrained objects/bones is not yet supported. The pasted animation may not match the copied animation.
- There is a new option to wrap the playhead to the playback range when navigating the timeline (blender/blender@675d94bd4bebef690c1703aef87d90fee84f95ea).
- Motion Paths now update faster when they are automatically updated from auto keying (blender/blender@6f69604f84aca01ef08ba538a1a78a57357a6212).
- "Fix to Camera" now also covers lens parameters (Focal Length, Field of View, Shift X/Y) as well (blender/blender@2291b97662898c2f363014b0c57f7c84b29585a5). There is a [demo video on video.blender.org](https://video.blender.org/w/siQckdy9NyFGpZRThGfNE6).
- Scrubbing now pauses playback, resumes on release (blender/blender@bda97c843c8f8571ce9f85b029321eada8e2becf).

## Shape Keys
- Duplicate operator now duplicates all selected shape keys, not just the active one (blender/blender@9851c6b1c5).

## Python API

- New context member: `context.markers` that contains the relevant markers for the editor (blender/blender@3048200244b8acb082c5399bd8b2aab8170035dc). These are the scene markers, unless the context is an animation editor that's configured to show the legacy pose markers.

## Forward Compatibility

- Spline IK chains are now gracefully capped to 255 bones on file read (blender/blender@c63d0e8bf364c525bc59fe02146f39e7d9f6fb9b). This means that when a future version of Blender increases the limit, Blender 5.3 will be able to read that new file without crashing.
