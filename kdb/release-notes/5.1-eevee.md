# Blender 5.1: EEVEE & Viewport

## EEVEE

### Shader Raycast Node

The new Raycast node allows casting rays against the scene geometry. (blender/blender@f7f6bdac6e169adc155dd058e05565586667efb8, [Manual](https://docs.blender.org/manual/en/5.1/render/shader_nodes/input/raycast.html))

This allows for a wide variety of effects, including NPR stylization integrated with scene shading.
It is currently limited to screen-space tracing in EEVEE.

### Light Path Intensity

Two new light path intensity properties allow for global tweaking of light path contributions. (blender/blender@7c44fae9d42cf6a8656f8ac7c03ee329e531c02d)

| Indirect Light Intensity = 1 | Indirect Light Intensity = 5 |
|---|---|
| ![Indirect Light Intensity 1](images/rt_scale1.png) | ![Indirect Light Intensity 5](images/rt_scale5.png) |

(Render by Trita Norouzi based on a scene by Aidan Sanderson)

This only affects the final pixel contribution and does not affect light transport.
This approach is similar to compositing while being more lightweight and compatible with
all EEVEE material types.

## Performance

### Material compilation

EEVEE Materials are compiled faster by pre-compiling GPU pipelines at the same time.
GPU shaders compile faster on all platforms due to pre-processing the shader sources.

| Version | Backend | Scene               | Cold  | Warm | 
| ------- | ------- | ------------------- | ----- | ---- |
| 5.0.1   | OpenGL  | barbershop_interior | 44.19 | 5.68 |
| 5.1     | OpenGL  | barbershop_interior | 30.39 | 6.51 |
| 5.0.1   | Vulkan  | barbershop_interior | 24.87 | 5.22 |
| 5.1     | Vulkan  | barbershop_interior | 11.67 | 5.93 |
| 5.0.1   | Metal   | barbershop_interior | 55.50 | 1.18 |
| 5.1     | Metal   | barbershop_interior | 37.20 | 2.72 |

Cold means without shader caching. Warm means with shader caching.
The overhead of the warm case will be addressed in the next release.

Tests have been conducted on NVIDIA RTX 6000 Ada, with NVIDIA 580.126.09 drivers on a AMD Ryzen 9 7950X 16-Core Processor.
For Metal, tests have been conducted on a Apple M1 Ultra on macOS Tahoe 26.2.

- Parallel material pipeline compilation. (blender/blender@9b02e462c638f5eab3ab43a736b746ef1c1e1c4f)
- Shader source preprocessor (blender/blender@9c457ddf070e0c0acf5ccdcdcf4723ab3e401726)

### Memory savings

EEVEE saves some texture memory by overlapping framebuffer and render textures at 
different times in a frame. Tests run on NVIDIA RTX A6000 on the *Mr. Elephant* scene.

| Version | Backend | Texture pool size | 
| ------- | ------- | ----------------- |
| 5.0.1   | Either  | 406mb             | 
| 5.1	  | OpenGL  | 291mb             |
| 5.1	  | Vulkan  | 245mb             |
