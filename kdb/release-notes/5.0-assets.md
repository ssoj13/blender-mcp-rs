# Blender 5.0: Assets

## General

* Scenes can now be marked as assets. A preview is generated using the active camera of the scene. When dragging from the asset browser, the scene asset will be imported (if it's not local to the file) and become the active scene (blender/blender@ba3eaf3a841388a6e5e44677662be4bffd787e04).
* The new _Packing_ import method is the default for custom asset libraries, see [Core - Packed Data](core.md#packed-data).
* Some Python API types, properties and functions were removed, see [Python API - Assets](python_api.md#assets).

## Asset Bundles

Some updates were done to the official [Asset Bundles](https://www.blender.org/download/demo-files/#assets).

- The Human Base Meshes asset bundle has been updated with a new community contribution. The full realistic skeleton asset has been added to the selection.

  ![](images/skeleton_base_mesh.jpg)
- The Ellie Pose Library asset bundle has been updated for Blender 4.0, using the Asset Shelf as new place to access pose assets.
