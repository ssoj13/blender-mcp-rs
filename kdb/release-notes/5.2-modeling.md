# Blender 5.2 LTS: Modeling & UV

## Modeling

### General

- "Circle" from the Loop Tools add-on is now built in as "To Circle".
(blender/blender@d2fabc952a4ff6df9e6d28b76729e754f70cf188)

- "Space" from the Loop Tools add-on is now built in as "Space Edge Loops Evenly".
(blender/blender@abf193c6f8a8a20889812792db4161556e22b11f)

- "Flatten" from the Loop Tools add-on is now built in as "Flatten". 
(blender/blender@b35c52b395c11e07c60c4b66e11b09f093547609)

- Add support for snapping to lattice objects.
(blender/blender@8293c35c59035d682dea2bf7feac743f9dd5e883)

- Add support for interpolating vertex custom data when merging vertices.
(blender/blender@0f4b405089f336d96ead5f2eaa92e51c62fb6393)


### 3D Text
