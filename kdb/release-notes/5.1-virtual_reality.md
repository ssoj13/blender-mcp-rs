# Blender 5.1: Virtual Reality

## Arc teleportation ray drawing and functionality overhaul 

The XR Arc Teleportation functionality was completely rewritten and overhauled, making it closer to the sort of arc ray locomotion typically found in modern VR video-games and softwares. (blender/blender@899ce2e182cd75943c5ac252be695f80a4311076)

Main user facing changes include:

- The teleportation ray arc parabola is now pre-computed and fixed, allowing for more predictable trajectories and precise aiming.
- New destination pad of cylindrical shape, drawn in world space, to clearly show the user destination
- Walls and other non-planar surfaces are now considered inaccessible, displayed using a red ray and sphere shaped destination indicator.
- New world ground grid intersection heuristics:
   - The arc teleportation ray will now stop at the world ground grid *only* if no accessible geometry exists below, allowing to teleport to surfaces below the ground grid.
   - The arc teleportation ray will now stop at the world ground grid in the *downward* direction only, allowing to teleport to geometry above the ground grid, or to the ground grid itself from below in an arc.

## New View Scale property

A new View Scale property was added to the VR Scene Inspection settings, allowing for session specific view fine tuning (such as accounting for subtle differences between real-world user heights, user positions, HMD offsets, etc...). In addition to this property, the current scene unit scale is also now taken into account when computing the overall VR navigation scale. (blender/blender@2ece88d367e299533d3005a4dbffa969b14bd2b6)

![New VR View Scale property](images/xr_view_scale_property.png)
 
## OpenXR support on macOS

A new Metal OpenXR graphics binding has been implemented, bringing preliminary VR support to Blender on macOS. (blender/blender@37899b82456eea164651ea1298735730a752fe67)

While no actual OpenXR hardware VR headset runtime currently exists for macOS yet, simulator software, such as the Meta XR Simulator, currently allows testing the implementation.

![Blender running with the Meta XR Simulator on macOS](images/macos_xr_simulator.png)


## Vulkan performance

The Vulkan OpenXR graphics binding has been rewritten, now trying to reuse the vulkan instance of Blender, resulting in major speedups (blender/blender@4e6a2b52ca4842be665188050b38ca6479dbf9c9).
