# Blender 5.2 LTS: Animation & Rigging

- 'Copy Constraints' has been added to the Link/Transfer Data (Ctrl+L) menu (blender/blender@3d20a0a017bb89e9b957db212b03a321c715a95f).
- Auto IK's reverse IK behavior can now activate even if a bone has a non-connected parent (blender/blender@c60fd454b5238fa08d27f0d33cea159016c9058b)
- The Dope Sheet got a new operator to select keys by their type (`action.select_by_type`). This can be found in the Dope Sheet under `Select`->`Select by Type` (blender/blender@1447bfd22bbcbc4492bfa7038756d923be197bd9).
- The armature edit mode got a new operator `Duplicate and Rename` that duplicates selected bones and performs a search/replace on the name. This can be used to avoid getting the ".001" suffix when duplicating bones. The operator can be found in the 3D viewport under the Armature menu (blender/blender@f67497581bd7d30ec76828368b14ca6ea6958fe2).
- The user preference "Only Insert Available" will now be on by default (blender/blender@32f621c6b44f6e96f9e69e36a31c3f0800d69627).
- When transforming an object or bone with a motion path and auto-keying enabled the line is no longer updated for the current frame. (blender/blender@2d3427f87d865f5161ec32c960c0af1e2dfc7085)
- A `Head/Tail` slider has been added to adjust positioning along a bone when using Bone parenting. (blender/blender@0ee66b616554f2d23c77762764c1cc10c12b1be9)
- When adding bones, additional options are now available in the redo panel. The options are "Space", "Align", "Length" and "Deform" (blender/blender@542fcc4a33858a91ea05265fa1e27b44ac6ebdde, [Manual](https://docs.blender.org/manual/en/5.2/animation/armatures/bones/add_bones.html)).
- There is a new operator to select markers left or right of the playhead (blender/blender@f5919335ac2d2bf6e090892b68d189e5920a9314). The hotkeys `[` and `]` in the markers area have been assigned to this operator.

## In-Between Tools
The operators to create in-betweens have been updated to be usable in object mode (blender/blender@d00c0d81e09e9aa256118adf788ee06e283c5629, [Manual](https://docs.blender.org/manual/en/5.2/animation/in_betweens.html)).
They can be found in the 3D viewport under `Object`->`Animation`->`In-Betweens`.
Some of the operators can also be accessed via a tool in the toolbar.

## Playback

* The option "Allow Preroll" was added the Playback popover (blender/blender@511bb630c1e0bd65676ac4ceeef22fa58f3674aa). With this option enabled, Blender allows playing back frames that are before the defined playback start frame. This also affects scrubbing while playing back. Note that this option does not override the user preference "Allow Negative Frames".
- A new operator `screen.animation_pause` was added (blender/blender@4db30c1c78c4f4c6c9daf4c00bd3f0bca24d4c8a). This operator will always pause playback (if playback was already paused, it does nothing); this is contrary to the already-existing `screen.animation_play` operator, which always toggles playback (so if it was paused, it will play again).

### Loop Modes

The Playback popover has been extended with the following options to control Blender's looping behavior when playing back animation (blender/blender@24f8c40b03ed16f148433f9bb8bfcc6327b0eaaa):

- **Infinite:** default behavior, after the last frame loop back to the first and continue playback.
- **Stop at End Frame:** stop playback at the last frame. Starting playback from the last frame will loop to the first frame once, then stop at the last frame again.
- **Stop at Start Frame:** after reaching the last frame, stop playback and go to the first frame.
- **Restore Frame:** after reaching the last frame, stop playback and go to the frame playback started from (as if pressing Escape).
- **Bounce:** after reaching the last frame, reverse playback.

## Pose Library

When applying a pose with a different rotation mode Blender tries to correct for that (blender/blender@ca786c2677d9b67293a9d9791e420951bc7a72f9). This behaves differently under various conditions.

| Pose Asset | Bone | Result |
| - | - | - |
| Quaternion/Axis Angle | Euler | Converted by finding the closest euler angle to the existing rotation |
| Euler | Quaternion/Axis Angle | Assumes that the euler pose was stored in XYZ rotation order. Blender has no way of knowing is that is true or not |
| Euler | Euler | Nothing changes. Blender assumes the stored rotation order is that of the bone |

## Notable Fixes
- When selecting parent or child bones in Pose Mode (`[` and `]` hotkeys), it now works on all selected bones instead of just the active (blender/blender@5dfad6abb338e65b600ecd840caa1715ae97c7f7).
- The transform lock settings of mirror bones are now respected (blender/blender@71bf78444d4bfa18b8fe0a7a3759e68bdb517993).
- The In-Between tools now work with x-mirror in pose mode (blender/blender@7017225b2083815626381164274bccc6781bf885).
- Motion paths now display correctly when using the option "Bake to Active Camera" while having animated camera properties like Focal Length (blender/blender@37f4979aa9a481082673ad00be772ea1b2f47a3f).
