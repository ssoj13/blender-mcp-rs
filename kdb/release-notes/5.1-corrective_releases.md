# Blender 5.1: Corrective Releases

## Blender 5.1.2

Released on May 19th 2026, Blender 5.1.2 features 12 bug fixes:

* Altering a text object to include some extrusion results in filled-in holes. (blender/blender#156286)
* Crash in BLI_mmap.cc on WIN32. (blender/blender@956fd000a2)
* Even-odd CDT non-zero winding producing empty output for concave polygons. (blender/blender#156687)
* GLTF/GLB export ignores light color. (blender/blender#156753)
* Hard crash when going into edit mode on an object after using "Make Instance Face" and then duplicating the object. (blender/blender#156158)
* LineArt: Collection intersection flags and priority inheritance not working. (blender/blender#156431)
* LineArt: Make intersection lines follow face mark filtering. (blender/blender@064c5791fd)
* Negative ref-count assert in debug builds using `bpy_run_string_exec_with_locals_assume_gil`. (blender/blender@67906c6e85)
* Prevent crashes whan an empty attribute is read as single value. (blender/blender#156765)
* Text object triangulation can fail when extruded. (blender/blender#155733)
* Vulkan: Backport texture pool workaround for Intel Windows. (blender/blender@76c4dfd8d1)
* Vulkan: Continuous memory leak on all viewport interactions — Intel Iris Xe 13th Gen. (blender/blender#157777)
