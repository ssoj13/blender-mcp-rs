# Blender 5.1: Animation & Rigging

## Performance

In Blender 5.1 the evaluation performance of the animation system has seen a boost ([#149405](https://projects.blender.org/blender/blender/issues/149405)). In short: Actions and Shapekeys evaluate a lot faster. The effect will be more noticeable on armatures with a lot of keyed bones and shapekeys with a lot of vertices.

All tests are an average time per frame when playing back.
The tests were run on a 12 core 24 thread CPU (AMD Ryzen 9 9900X) on Linux. For benchmarks on different systems see the [Daily Benchmarks](https://builder.blender.org/tests).

- Action evaluation speed was tested with an [armature of 2600 bones](https://projects.blender.org/blender/blender-benchmarks/src/branch/main/animation/synthetic_tests/high_bone_count_armature.blend) that are keyed for ~1000 frames.
- Shapekey evaluation speed was tested with a mesh of around [1 million vertices](https://projects.blender.org/blender/blender-benchmarks/src/branch/main/animation/synthetic_tests/high_poly_shapekey.blend).
- Production file speed was tested with the [Hi, my name is Amy](https://studio.blender.org/characters/rain/showcase/1/) file from the Blender Studio.


| - | 5.0 | 5.1 | fps increase |
| - | - | - | - |
| Action Evaluation 4 threads | 32.8 fps (30.5 ms) | 74.1 fps (13.5 ms) | **+125%** |
| Action Evaluation 8 threads | 31.0 fps (32.2 ms) | 76.3 fps (13.1 ms) | **+146%** |
| Action Evaluation 24 threads | 32.2 fps (31.1 ms) | 74.1 fps (13.5 ms) | **+130%** |
| - | - | - | - |
| Shapekey Evaluation 4 threads | 48.7 fps (20.5 ms) | 112.3 fps (8.9 ms) | **+130%** |
| Shapekey Evaluation 8 threads | 44.2 fps (22.6 ms) | 151.5 fps (6.6 ms) | **+240%** |
| Shapekey Evaluation 24 threads | 39.2 fps (25.5 ms) | 158.7 fps (6.3 ms) | **+304%** |
| - | - | - | - |
| Production file 4 threads | 91.7 fps (10.9 ms) | 96.2 fps (10.4 ms) | **+4%** |
| Production file 8 threads | 102.0 fps (9.8 ms) | 112.4 fps (8.9 ms) | **+10%** |
| Production file 24 threads | 91.7 fps (10.9 ms) | 105.3 fps (9.5 ms) | **+14%** |


## Animation

- New operator to replace the action on multiple objects (blender/blender@0760e3a380db8ca1d1c6f5774378f65ff44552c2, [Manual](https://docs.blender.org/manual/en/5.1/editors/dope_sheet/modes/action.html#action-menu)). This operator looks at the action of the active object and finds all users of said action. Then it replaces the action of all those users with a different action that can be chosen in a popup. This operator can be found in the 3D viewport under "(Object or Pose)->Animation" and in the Action editor under "Action". There is a version of this operator that creates a new action instead. It can be found just below the "Replace Action" operator and is called "Replace with new Action".
- A new F-Curve modifier was added called "Gaussian Smooth" (blender/blender@2cbfb36a8b8874c6af401f687b3672cfaac11549, [Manual](https://docs.blender.org/manual/en/5.1/editors/graph_editor/fcurves/modifiers.html#smooth-gaussian-modifier)). This allows to non-destructively smooth F-Curves. For technical reasons, the modifier has to be in the first position of the modifier stack to work.

## Shape Keys

- The new "Apply to Basis" operator applies the deformations of the selected shape keys to the basis key and then removes them (blender/blender@56049e5a2303, [Manual](https://docs.blender.org/manual/en/5.1/animation/shape_keys/shape_keys_panel.html#bpy-ops-object-shape-key-apply-to-basis)).


## Python
- The operator `ANIM_OT_convert_legacy_action` was removed. Since all actions are automatically layered already it couldn't be used since the change to layered actions in 4.4 (blender/blender@8134983884d5eedd615c3e24f85cc47ed9fc4567).


## Notable Fixes
- When deleting a bone, any constraints on it will be removed when leaving edit mode (blender/blender@b6a84566b9f8baad2d9316081a21c57b7df51d08).
- Auto-keying works properly now when using the picker on the focus distance depth of the camera (blender/blender@bdc276594edfb633db48f5079ab0df575b440be7)
- Drivers are no longer lost when renaming a bone (blender/blender@bce83c83b17e5f01441af9fe6870a8b36f10adb1)
- Circle select in Pose Mode now correctly selects based on the shape visible on screen (blender/blender@bc587ce3a03aad92bc48953cd0a99b93d50d08d9).
