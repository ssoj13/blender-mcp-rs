# Blender 5.2 LTS: Sequencer

## User Interface

### Compositor in VSE

New "Compositor" effect: an effect strip that uses zero, one or two inputs, and the actual effect is implemented with
a compositor node tree. The node tree input group gets the input images and a float "effect fader" input. (blender/blender!150694)

- Compositor modifiers & effects within VSE can use GPU acceleration now. This is controlled in the same place as regular compositor
  execution device (`Render -> Performance -> Compositor`). Note that only the individual modifiers/effects run on the GPU, with their
  results transfered to and from CPU memory. This generally means that simple node graphs might not even be faster on the GPU, but
  more complex graphs or anything with large blurs is generally faster. (blender/blender!154629, blender/blender!154914, blender/blender!156640)
- Compositor modifiers now support arbitrary inputs, including menus, input panels with panel toggles and more. The inputs come from the node group interface that the assigned compositor node group of the modifier uses. When changing the node group interface through the node editor, inputs can be added, renamed, removed, etc. This is the same system that Geometry Nodes uses. (blender/blender!156706)
- The compositor modifier extras menu now has an option to hide the node group data-block selector. This is especially useful for modifier assets where the selector is redundant. Hiding the node group selector makes the assets look more like built-in modifiers (blender/blender!157360).
- Compositor node tree assets show up in the strip modifier "Add" menu. In the node tree "Usages" the option "Strip Modifier" has to be set for this. When a compositing node tree is created for a strip modifier, this option is set by default (blender/blender@a1f0e91f95858347e61ed3f672c628e168f8e596).

### Timeline

- Strip thumbnails are shown at start/end of strip by default now. There is an option
  to show them across whole strip. (blender/blender!151148)
- Prefetch now also pre-fetches five frames before the playhead, making it faster to reverse by a small number of frames when editing footage. (blender/blender!154537)

### Text Strips

- Text strips now support adjusting line spacing in between separate lines. (blender/blender!157660)
  - Line spacing may either be calculated relative to the font size, or an absolute amount in pixels, toggleable by button. The latter option is useful for keeping spacing fixed while adjusting font size. (blender/blender!158585)
- Text strips now support **style presets**. Most settings in the Style and Layout panels are saved as part of the presets, and three default styles have been added: Subtitles, Main Title, Corner Title. Find it in the header of the Effect Strip panel. (blender/blender@e6a2fde77e)

### Scene Strips

- Scene strips now have a view layer selector, initially set to the default view layer. (blender/blender!157495)
- Added the option to override the workbench world settings, allowing to tweak background color for all scene strips at once. (blender/blender!149656)
- Whenever there are no scene other than the Edit in the file, the Add Menu shows "No other scenes." under Scene Strip. (blender/blender!154387)

### Strip Modifiers

- Added the "extras" dropdown-menu for strip modifiers similar to object modifiers (blender/blender!154375). The menu has options to
  - Duplicate the modifier (also using the shortcut `Shift+D`).
  - Copy the modifier to the selected strips.
  - Move the modifier to the first/last position in the modifier stack.
- Removed "Linear Modifiers" strip option. The option was inconsistently implemented (e.g. did nothing for non-HDR inputs),
  and originally added as a hack. (blender/blender!156312)
- Added a preview visibility toggle to strip modifiers similar to object modifiers. (blender/blender!146955).
  - This change also means that final frame caches are no longer unnecessarily cleared after rendering, and are kept in memory, improving performance with identical results.

![Modifier Preview Toggle](images/vse_modifier_preview.png)


### Scopes

Scopes now support HDR and wide gamut color spaces. (blender/blender!157031)

- HDR color spaces are plotted with a log scale and show grid lines in nits.
- Scopes encompass the full gamut of the display color space for P3 and Rec.2020.
- Clipped colors are more clear due to padding around minimum and maximum.

### Miscellaneous
- A new optional scrubbing region was added onto the VSE playback controls footer, which allows the preview to have its own scrub bar that spans the entire playback range and clamps the playhead to its extents. (blender/blender!155377)
- All audio and video streams from video files are now properly added when importing files into the sequencer. (blender/blender!158248)
- The "Render Audio" operator now shows a realtime progress bar that can be cancelled (previously Blender would freeze until the operation finished). (blender/blender!155623)
- Composition guides have been added to the VSE preview, with matching options as 3D viewport cameras. Individual options are toggleable in the N-panel (sidebar). (blender/blender!157117)
- Color strip size can now be set in raw pixels from the Strip Properties > Transform menu. (blender/blender!158778)
- Strip image origins now have more snap options, such as the preview center. (blender/blender!156508) 

## Performance

- Conversion of footage or compositor modifier/effect results into "Sequencer color space" is now done on demand instead of immediately.
  In some cases this saves redundant color space conversions, improving performance. However, strips that are scaled or rotated now
  perform image filtering in their current color space, which can alter the look a bit (in case of linear color space, e.g. images
  from EXR files, the new filtering results are arguably better). (blender/blender!156281)
- Compositor modifiers now automatically detect whether the result is fully opaque or semitransparent (fully opaque strips allow certain
  parts of rendering be faster). Previously they were assuming they contain transparency, taking the slower path. (blender/blender!158600)
- Mask datablock inputs are rendered faster now, especially when used in Compositor strip modifier. (blender/blender!155853, blender/blender!156518, blender/blender!156622)

## Python API
- Added collection strip property `.connections` to get all of the strips connected to a given strip. (blender/blender!154705)
- `strips.new_movie` and `strips.new_sound` now support an optional `stream` parameter for specifying the video/audio stream index to import from the original file. By default it is 0 which is backwards-compatible and produces old behavior. (blender/blender!159194)
- Removed strip property `.use_linear_modifiers`. (blender/blender!156312)

## Compatibility
- Prior to 5.2, in compositor strip modifier node trees, the mask input would be black & fully transparent when no mask was selected in the modifier. In 5.2 the modifier now supports inputs and specifically unused mask inputs will now be black, but fully opaque.
- Sequencer colorspace transforms with semitransparent images now match the compositor Convert Colorspace node behavior.
  This fixes artifacts around edges of emissive colors (e.g. as produced by compositor Glow node) when they are coming into sequencer from
  EXR files or scene strips. However it also slightly changes the look of semitransparent areas. (blender/blender!159793)
- Movie strip "timecode files" functionality has been removed. Now building proxies just builds the proxies; `*.blen_tc` timecode files are no longer produced. (blender/blender!158840)
