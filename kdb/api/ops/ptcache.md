# Blender 5.2.2 operators: bpy.ops.ptcache

- `bpy.ops.ptcache.add()` — Add new cache
- `bpy.ops.ptcache.bake(bake: boolean)` — Bake physics
- `bpy.ops.ptcache.bake_all(bake: boolean)` — Bake all physics simulations in the current scene
- `bpy.ops.ptcache.bake_from_cache()` — Bake from cache
- `bpy.ops.ptcache.free_bake()` — Delete physics bake
- `bpy.ops.ptcache.free_bake_all()` — Delete all baked caches of all objects in the current scene
- `bpy.ops.ptcache.remove()` — Delete current cache
