# Blender 5.2.2 operators: bpy.ops.world

- `bpy.ops.world.convert_volume_to_mesh()` — Convert the volume of a world to a mesh. The world's volume used to be rendered by EEVEE Legacy. Conversion is needed for it to render properly
- `bpy.ops.world.new()` — Create a new world Data-Block
