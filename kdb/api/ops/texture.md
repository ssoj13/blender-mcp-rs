# Blender 5.2.2 operators: bpy.ops.texture

- `bpy.ops.texture.new()` — Add a new texture
- `bpy.ops.texture.slot_copy()` — Copy the material texture settings and nodes
- `bpy.ops.texture.slot_move(type: enum{UP, DOWN})` — Move texture slots up and down
- `bpy.ops.texture.slot_paste()` — Paste the texture settings and nodes
