# Blender 5.2.2 RNA types: object

## CacheObjectPath

Path of an object inside of an Alembic archive

- `path` · string — Object path

## CollectionObject

Object of a collection with its collection related settings

- `light_linking` · pointer · -> CollectionLightLinking · read-only — Light linking settings of the collection

## DepsgraphObjectInstance

Extended information about dependency graph object iterator (Warning: All data here is 'evaluated' one, not original .blend IDs)

- `object` · pointer · -> Object · read-only — Evaluated object the iterator points to
- `show_self` · boolean · read-only — The object geometry itself should be visible in the render
- `show_particles` · boolean · read-only — Particles part of the object should be visible in the render
- `is_instance` · boolean · read-only — Denotes if the object is generated by another object
- `instance_object` · pointer · -> Object · read-only — Evaluated object which is being instanced by this iterator
- `parent` · pointer · -> Object · read-only — If the object is an instance, the parent object that generated it
- `particle_system` · pointer · -> ParticleSystem · read-only — Evaluated particle system that this object was instanced from
- `persistent_id` · int · [8] · read-only — Persistent identifier for inter-frame matching of objects with motion blur
- `random_id` · int · read-only — Random id for this instance, typically for randomized shading
- `matrix_world` · float · [16] · read-only — Generated transform matrix in world space
- `orco` · float · [3] · read-only — Generated coordinates in parent object space
- `uv` · float · [2] · read-only — UV coordinates in parent object space

## LayerObjects

Collections of objects

- `active` · pointer · -> Object — Active object for this layer
- `selected` · collection · read-only — All the selected objects of this layer

## MovieTrackingObject

Match-moving object tracking and reconstruction data

- `name` · string — Unique name of object
- `is_camera` · boolean · read-only — Object is used for camera tracking
- `tracks` · collection · [] of MovieTrackingObjectTracks · read-only — Collection of tracks in this tracking data object
- `plane_tracks` · collection · [] of MovieTrackingObjectPlaneTracks · read-only — Collection of plane tracks in this tracking data object
- `reconstruction` · pointer · -> MovieTrackingReconstruction · read-only
- `scale` · float — Scale of object solution in camera space
- `keyframe_a` · int — First keyframe used for reconstruction initialization
- `keyframe_b` · int — Second keyframe used for reconstruction initialization

## MovieTrackingObjectPlaneTracks

Collection of tracking plane tracks

- `active` · pointer · -> MovieTrackingTrack — Active track in this tracking data object

## MovieTrackingObjectTracks

Collection of movie tracking tracks

- `active` · pointer · -> MovieTrackingTrack — Active track in this tracking data object

## MovieTrackingObjects

Collection of movie tracking objects

- `active` · pointer · -> MovieTrackingObject — Active object in this tracking data object

## Object

Object data-block defining an object in a scene

- `data` · pointer · -> ID — Object data
- `type` · enum · {MESH, CURVE, SURFACE, META, FONT, CURVES, POINTCLOUD, VOLUME, GREASEPENCIL, ARMATURE, LATTICE, EMPTY, LIGHT, LIGHT_PROBE, CAMERA, SPEAKER} · read-only — Type of object
- `mode` · enum · {OBJECT, EDIT, POSE, SCULPT, VERTEX_PAINT, WEIGHT_PAINT, TEXTURE_PAINT, PARTICLE_EDIT, EDIT_GPENCIL, SCULPT_GREASE_PENCIL, PAINT_GREASE_PENCIL, WEIGHT_GREASE_PENCIL, VERTEX_GREASE_PENCIL, SCULPT_CURVES} · read-only — Object interaction mode
- `bound_box` · float · [24] · read-only — Object's bounding box in object-space coordinates, all values are -1.0 when not available
- `parent` · pointer · -> Object — Parent object
- `parent_type` · enum · {OBJECT, ARMATURE, LATTICE, VERTEX, VERTEX_3, BONE} — Type of parent relation
- `parent_vertices` · int · [3] — Indices of vertices in case of a vertex parenting relation
- `parent_bone` · string — Name of parent bone in case of a bone parenting relation
- `parent_bone_head_tail_factor` · float — Position along the length of bone
- `use_parent_final_indices` · boolean — Use the final evaluated indices rather than the original mesh indices
- `use_camera_lock_parent` · boolean — View Lock 3D viewport camera transformation affects the object's parent instead
- `track_axis` · enum · {POS_X, POS_Y, POS_Z, NEG_X, NEG_Y, NEG_Z} — Axis that points in the 'forward' direction (applies to Instance Vertices when Align to Vertex Normal is enabled)
- `up_axis` · enum · {X, Y, Z} — Axis that points in the upward direction (applies to Instance Vertices when Align to Vertex Normal is enabled)
- `material_slots` · collection · read-only — Material slots in the object
- `active_material` · pointer · -> Material — Active material being displayed
- `active_material_index` · int — Index of active material slot
- `location` · float · [3] — Location of the object
- `rotation_quaternion` · float · [4] — Rotation in Quaternions
- `rotation_axis_angle` · float · [4] — Angle of Rotation for Axis-Angle rotation representation
- `rotation_euler` · float · [3] — Rotation in Eulers
- `rotation_mode` · enum · {QUATERNION, XYZ, XZY, YXZ, YZX, ZXY, ZYX, AXIS_ANGLE} — The kind of rotation to apply, values from other rotation modes are not used
- `scale` · float · [3] — Scaling of the object
- `dimensions` · float · [3] — Absolute bounding box dimensions of the object.
Warning: Assigning to it or its members multiple consecutive times will not work correctly, as this needs up-to-date evaluated data
- `delta_location` · float · [3] — Extra translation added to the location of the object
- `delta_rotation_euler` · float · [3] — Extra rotation added to the rotation of the object (when using Euler rotations)
- `delta_rotation_quaternion` · float · [4] — Extra rotation added to the rotation of the object (when using Quaternion rotations)
- `delta_scale` · float · [3] — Extra scaling added to the scale of the object
- `lock_location` · boolean — Lock editing of location when transforming
- `lock_rotation` · boolean — Lock editing of rotation when transforming
- `lock_rotation_w` · boolean — Lock editing of 'angle' component of four-component rotations when transforming
- `lock_rotations_4d` · boolean — Lock editing of four component rotations by components (instead of as Eulers)
- `lock_scale` · boolean — Lock editing of scale when transforming
- `matrix_world` · float · [16] — Worldspace transformation matrix
- `matrix_local` · float · [16] — Parent relative transformation matrix.
Warning: Only takes into account object parenting, so e.g. in case of bone parenting you get a matrix relative to the Armature object, not to the actual parent bone
- `matrix_basis` · float · [16] — Matrix access to location, rotation and scale (including deltas), before constraints and parenting are applied
- `matrix_parent_inverse` · float · [16] — Inverse of object's parent matrix at time of parenting
- `modifiers` · collection · [] of ObjectModifiers · read-only — Modifiers affecting the geometric data of the object
- `shader_effects` · collection · [] of ObjectShaderFx · read-only — Effects affecting display of object
- `constraints` · collection · [] of ObjectConstraints · read-only — Constraints affecting the transformation of the object
- `vertex_groups` · collection · [] of VertexGroups · read-only — Vertex groups of the object
- `empty_display_type` · enum · {PLAIN_AXES, ARROWS, SINGLE_ARROW, CIRCLE, CUBE, SPHERE, CONE, IMAGE} — Viewport display style for empties
- `empty_display_size` · float — Size of display for empties in the viewport
- `empty_image_offset` · float · [2] — Origin offset distance
- `image_user` · pointer · -> ImageUser · read-only — Parameters defining which layer, pass and frame of the image is displayed
- `empty_image_depth` · enum · {DEFAULT, FRONT, BACK} — Determine which other objects will occlude the image
- `show_empty_image_perspective` · boolean — Display image in perspective mode
- `show_empty_image_orthographic` · boolean — Display image in orthographic mode
- `show_empty_image_only_axis_aligned` · boolean — Only display the image when it is aligned with the view axis
- `use_empty_image_alpha` · boolean — Use alpha blending instead of alpha test (can produce sorting artifacts)
- `empty_image_side` · enum · {DOUBLE_SIDED, FRONT, BACK} — Show front/back side
- `add_rest_position_attribute` · boolean — Add a "rest_position" attribute that is a copy of the position attribute before shape keys and modifiers are evaluated
- `pass_index` · int — Index number for the "Object Index" render pass
- `color` · float · [4] — Object color and alpha, used when the Object Color mode is enabled
- `field` · pointer · -> FieldSettings · read-only — Settings for using the object as a field in physics simulation
- `collision` · pointer · -> CollisionSettings · read-only — Settings for using the object as a collider in physics simulation
- `soft_body` · pointer · -> SoftBodySettings · read-only — Settings for soft body simulation
- `particle_systems` · collection · [] of ParticleSystems · read-only — Particle systems emitted from the object
- `rigid_body` · pointer · -> RigidBodyObject · read-only — Settings for rigid body simulation
- `rigid_body_constraint` · pointer · -> RigidBodyConstraint · read-only — Constraint constraining rigid bodies
- `use_simulation_cache` · boolean — Cache frames during simulation nodes playback
- `hide_viewport` · boolean — Globally disable in viewports
- `hide_select` · boolean — Disable selection in viewport
- `hide_render` · boolean — Globally disable in renders
- `hide_probe_volume` · boolean — Globally disable in volume probes
- `hide_probe_sphere` · boolean — Globally disable in spherical light probes
- `hide_probe_plane` · boolean — Globally disable in planar light probes
- `hide_surface_pick` · boolean — Disable surface influence during selection, snapping and depth-picking operators. Usually used to avoid semi-transparent objects to affect scene navigation
- `show_instancer_for_render` · boolean — Make instancer visible when rendering
- `show_instancer_for_viewport` · boolean — Make instancer visible in the viewport
- `visible_camera` · boolean — Object visibility to camera rays
- `visible_diffuse` · boolean — Object visibility to diffuse rays
- `visible_glossy` · boolean — Object visibility to glossy rays
- `visible_transmission` · boolean — Object visibility to transmission rays
- `visible_volume_scatter` · boolean — Object visibility to volume scattering rays
- `visible_shadow` · boolean — Object visibility to shadow rays
- `is_holdout` · boolean — Render objects as a holdout or matte, creating a hole in the image with zero alpha, to fill out in compositing with real footage or another render
- `is_shadow_catcher` · boolean — Only render shadows and reflections on this object, for compositing renders into real footage. Objects with this setting are considered to already exist in the footage, objects without it are synthetic objects being composited into it.
- `visible_raycast` · boolean — Object visibility to raycast rays. Implicitly false for Blended materials.
- `instance_type` · enum · {NONE, VERTS, FACES, COLLECTION} — If not None, object instancing method to use
- `use_instance_vertices_rotation` · boolean — Rotate instance according to vertex normal
- `use_instance_faces_scale` · boolean — Scale instance based on face size
- `instance_faces_scale` · float — Scale the face instance objects
- `instance_collection` · pointer · -> Collection — Instance an existing collection
- `is_instancer` · boolean · read-only
- `display_type` · enum · {BOUNDS, WIRE, SOLID, TEXTURED} — How to display object in viewport
- `show_bounds` · boolean — Display the object's bounds
- `display_bounds_type` · enum · {BOX, SPHERE, CYLINDER, CONE, CAPSULE} — Object boundary display type
- `show_name` · boolean — Display the object's name
- `show_axis` · boolean — Display the object's origin and axes
- `show_texture_space` · boolean — Display the object's texture space
- `show_wire` · boolean — Display the object's wireframe over solid shading
- `show_all_edges` · boolean — Display all edges for mesh objects
- `use_grease_pencil_lights` · boolean — Lights affect Grease Pencil object
- `show_transparent` · boolean — Display material transparency in the object
- `show_in_front` · boolean — Make the object display in front of others
- `pose` · pointer · -> Pose · read-only — Current pose for armatures
- `show_only_shape_key` · boolean — Only show the active shape key at full value
- `use_shape_key_edit_mode` · boolean — Display shape keys in edit mode (for meshes only)
- `active_shape_key` · pointer · -> ShapeKey · read-only — Current shape key
- `active_shape_key_index` · int — Current shape key index
- `use_dynamic_topology_sculpting` · boolean · read-only
- `is_from_instancer` · boolean · read-only — Object comes from a instancer
- `is_from_set` · boolean · read-only — Object comes from a background set
- `display` · pointer · -> ObjectDisplay · read-only — Object display settings for 3D viewport
- `lineart` · pointer · -> ObjectLineArt · read-only — Line Art settings for the object
- `use_mesh_mirror_x` · boolean — Enable mesh symmetry in the X axis
- `use_mesh_mirror_y` · boolean — Enable mesh symmetry in the Y axis
- `use_mesh_mirror_z` · boolean — Enable mesh symmetry in the Z axis
- `lightgroup` · string — Lightgroup that the object belongs to
- `light_linking` · pointer · -> ObjectLightLinking · read-only — Light linking settings
- `shadow_terminator_normal_offset` · float — Offset rays from the surface to reduce shadow terminator artifact on low poly geometry. Only affect triangles that are affected by the geometry offset
- `shadow_terminator_geometry_offset` · float — Offset rays from the surface to reduce shadow terminator artifact on low poly geometry. Only affects triangles at grazing angles to light
- `shadow_terminator_shading_offset` · float — Push the shadow terminator towards the light to hide artifacts on low poly geometry
- `animation_data` · pointer · -> AnimData · read-only — Animation data for this data-block
- `animation_visualization` · pointer · -> AnimViz · read-only — Animation data for this data-block
- `motion_path` · pointer · -> MotionPath · read-only — Motion Path for this element
- `selection_sets` · collection · read-only — List of groups of bones for easy selection
- `active_selection_set` · int — Index of the currently active selection set
- `cycles` · pointer · -> CyclesObjectSettings · read-only — Cycles object settings

## ObjectBase

An object instance in a View Layer (currently never exposed in Python API)

- `object` · pointer · -> Object · read-only — Object this base links to
- `select` · boolean — Object base selection state
- `hide_viewport` · boolean — Temporarily hide in viewport

## ObjectDisplay

Object display settings for 3D viewport

- `show_shadows` · boolean — Object cast shadows in the 3D viewport

## ObjectLightLinking

- `receiver_collection` · pointer · -> Collection — Collection which defines light linking relation of this emitter
- `blocker_collection` · pointer · -> Collection — Collection which defines objects which block light from this emitter

## ObjectLineArt

Object Line Art settings

- `usage` · enum · {INHERIT, INCLUDE, OCCLUSION_ONLY, EXCLUDE, INTERSECTION_ONLY, NO_INTERSECTION, FORCE_INTERSECTION} — How to use this object in Line Art calculation
- `use_crease_override` · boolean — Use this object's crease setting to overwrite scene global
- `crease_threshold` · float — Angles smaller than this will be treated as creases
- `use_intersection_priority_override` · boolean — Use this object's intersection priority to override collection setting
- `intersection_priority` · int — The intersection line will be included into the object with the higher intersection priority value

## RigidBodyObject

Settings for object participating in Rigid Body Simulation

- `type` · enum · {ACTIVE, PASSIVE} — Role of object in Rigid Body Simulations
- `mesh_source` · enum · {BASE, DEFORM, FINAL} — Source of the mesh used to create collision shape
- `enabled` · boolean — Rigid Body actively participates to the simulation
- `collision_shape` · enum · {BOX, SPHERE, CAPSULE, CYLINDER, CONE, CONVEX_HULL, MESH, COMPOUND} — Collision Shape of object in Rigid Body Simulations
- `kinematic` · boolean — Allow rigid body to be controlled by the animation system
- `use_deform` · boolean — Rigid body deforms during simulation
- `mass` · float — How much the object 'weighs' irrespective of gravity
- `use_deactivation` · boolean — Enable deactivation of resting rigid bodies (increases performance and stability but can cause glitches)
- `use_start_deactivated` · boolean — Deactivate rigid body at the start of the simulation
- `deactivate_linear_velocity` · float — Linear Velocity below which simulation stops simulating object
- `deactivate_angular_velocity` · float — Angular Velocity below which simulation stops simulating object
- `linear_damping` · float — Amount of linear velocity that is lost over time
- `angular_damping` · float — Amount of angular velocity that is lost over time
- `friction` · float — Resistance of object to movement
- `restitution` · float — Tendency of object to bounce after colliding with another (0 = stays still, 1 = perfectly elastic)
- `use_margin` · boolean — Use custom collision margin (some shapes will have a visible gap around them)
- `collision_margin` · float — Threshold of distance near surface where collisions are still considered (best results when non-zero)
- `collision_collections` · boolean — Collision collections rigid body belongs to
